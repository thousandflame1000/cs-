每往上一層剩一半：第 $k$ 層期望 $n/2^{k-1}$。$1024/16=64$。

@q bt5-09 | ds-btree#5 | 2 | 觀念
A new skip-list node starts at height one and independently promotes with chance one quarter at each step until the first failed promotion. Its observed outcomes are success,success,failure. Existing nodes keep their original promotion outcomes as the list grows. Which statements are correct? Select all that apply.
[x] The new node's realized height is three.
[x] Without a height cap, its expected height under the rule is $4/3$.
[ ] Its height must equal the current number of stored elements.
[ ] Doubling the list size requires rerolling every old node's promotion outcomes under this rule.
[ ] The chance of reaching height at least three is one quarter.
---
「高度三」對：底層一，再成功提升兩次。「期望 4/3」對：1＋1/4＋1/16＋…＝1/(1−1/4)。「等於元素數」錯：高度依本次提升結果。「變大就重抽全部」錯：題設與一般獨立提升做法都保留原有節點高度。「至少三層 1/4」錯：需兩次連續成功，機率為 (1/4)²＝1/16。

@q bt5-10 | ds-btree#5 | 3 | 情境
A leaderboard contains distinct scores 10,13,17,20 and needs predecessor/successor queries with updates. A skip list maintains a sorted bottom list; any concurrent implementation must coordinate its updates correctly. Consider a query around score 15. Which statements are correct? Select all that apply.
[x] The predecessor score is 13.
[x] An ordered skip-list search can use its located position to find adjacent stored scores.
[ ] The successor score is 20.
[ ] An ordinary hash table's unspecified iteration order automatically supplies sorted predecessor/successor relationships.
[ ] No balanced-tree implementation can support correct concurrent leaderboard operations.
---
「前驅 13」對：小於 15 的最大分數。「有序搜尋找鄰近」對：排序關係保存在底層鏈結與搜尋路徑。「後繼 20」錯：大於 15 的最小分數是 17。「雜湊迭代自然有序」錯：若沒有額外索引或掃描，不能從任意迭代次序直接得到這種關係。「平衡樹不能並行」錯：也可有正確並行實作；此處是比較結構取捨，不是宣稱只有單一結構能解決需求。
