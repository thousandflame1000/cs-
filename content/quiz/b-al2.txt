```
    if i >= n: return 0
    return max(v[i] + best(i + 2), best(i + 1))
```

?? 複選
[x] `best(0)` returns 10 by combining $v[0]$ with the optimal value `best(2)` of a shorter suffix.
[ ] The call `best(0)` evaluates `best(2)` exactly once, so this recursion has no overlapping subproblems.

@q gd3-09 | al-greedy#3 | 3 | 證明
