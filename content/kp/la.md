=== la-systems#1
title: 高斯消去法：解聯立方程式、看出解有幾個
mins: 40
goal: 會用列運算把增廣矩陣消到列梯形、RREF；分得出唯一解、無限多解、無解；會寫「特解＋齊次解」
---
> [!先記住]
> 把方程式寫成**增廣矩陣**，用列運算（交換、乘常數、某列加上另一列的倍數）消成**階梯形**。每列第一個非零的數叫**樞紐（pivot）**。樞紐的個數就是**秩**；沒有樞紐的那些行是**自由變數**。

```fig
matrix: 1 2 1 ; 0 0 1
pivot: 1,1 2,3
free: 2
name: U
cap: [1 2 1; 2 4 3] 消去後：樞紐在第 1、3 行，第 2 行是自由變數。零空間由 (−2, 1, 0) 張成
```

聯立方程式 $Ax=b$ 寫成**增廣矩陣** $[A\mid b]$，用三種**列運算**消去：
1. 兩列交換
2. 一列乘上一個不是 0 的數
3. 一列加上另一列的倍數

列運算**不會改變解**。目標是消成「階梯」的樣子（**列梯形**）。

?? 選擇 | 下面哪一個**不是**合法的列運算？
[ ] 第 1 列和第 2 列交換
[ ] 第 2 列減掉 3 倍的第 1 列
[x] 第 2 列乘上 0
!! 乘 0 之後還能變回來嗎？
>> 乘 0 會丟掉一條方程式，解會變多。其他兩個都能還原。

先看影片：三張水果收據，用消去法算出每種水果多少錢。

@影片 la-systems 0-75.8

每一列最左邊不是 0 的數叫 **pivot**（主元）。有 pivot 的變數可以解出來；**沒有 pivot 的變數叫自由變數**，可以隨便給值。

再往上消、把 pivot 都變成 1、pivot 上下都是 0，叫**簡化列梯形**（**RREF**）。RREF 是唯一的。

?? 填空 | 消完是 $\begin{bmatrix}1&2&0&\mid&3\\0&0&1&\mid&4\end{bmatrix}$（三個變數 $x_1,x_2,x_3$）。有幾個自由變數？
== 1
!! 哪一行沒有 pivot？
>> 第 1、3 行有 pivot，第 2 行沒有：$x_2$ 是自由變數。

再看影片：收據沒有新消息、或互相矛盾的時候，消完會長什麼樣子。

@影片 la-systems 75.9-134.4

解有三種情況（看消完的樣子）：
- 出現 $[0\ 0\ \cdots\ 0\mid c]$，$c\ne0$（$0=c$）：**無解**
- 沒有矛盾、**每個變數都有 pivot**：**唯一解**
- 沒有矛盾、**有自由變數**：**無限多解**

?? 選擇 | 消完得到 $\begin{bmatrix}1&1&\mid&2\\0&0&\mid&3\end{bmatrix}$。這組方程式？
[ ] 唯一解
[ ] 無限多解
[x] 無解
!! 第二列是什麼方程式？
>> 第二列是 $0x_1+0x_2=3$，不可能成立，無解。

最後一段影片：兩個變數時用直線看三種情況，還有考試陷阱。

@影片 la-systems 134.5-181.5

無限多解時，把解寫成「**特解＋齊次解**」：
$$x=x_p+x_n$$
$x_p$ 是任一個特解（自由變數都給 0 算出來），$x_n$ 是 $Ax=0$ 的所有解（自由變數當參數）。

上一題的例子 $x_1+2x_2=3$、$x_3=4$：令 $x_2=t$，$x=(3,0,4)+t(-2,1,0)$。

?? 排序 | 解 $Ax=b$ 的順序
- 寫出增廣矩陣 $[A\mid b]$
- 用列運算消成列梯形
- 檢查有沒有 $0=c$（$c\ne0$）的列
- 找出自由變數，寫成 $x_p+x_n$
>> 先消、再看矛盾、最後寫解。

@例題 解 $x+y+z=6$、$2x+3y+z=11$、$x+2y=5$。
@寫 寫出增廣矩陣，用第 1 列消掉下面兩列的 $x$ | $\begin{bmatrix}1&1&1&6\\0&1&-1&-1\\0&1&-1&-1\end{bmatrix}$
@寫 消掉第 3 列的 $y$ | 第 3 列減第 2 列：$[0\ 0\ 0\mid0]$。沒有矛盾，$z$ 沒有 pivot，是自由變數。
@寫 令 $z=t$，往回代 | $y=-1+t$，$x=6-y-z=7-2t$。
@答 $x=(7,-1,0)+t(-2,1,1)$，無限多解。

=== la-systems#2
title: 可逆矩陣：一大串互相等價的條件
mins: 30
goal: 會用 $[A\mid I]$ 求反矩陣；記得可逆矩陣定理裡最常考的幾個等價條件
---
> [!先記住]
> $n\times n$ 的方陣 $A$，下面這些說法**全部等價**，知道一個就知道全部。考試常給其中一個，要你推出另一個。

```fig
flow: A 可逆 -> det A ≠ 0 | rank A = n | N(A) = {0} | Ax = b 永遠恰一解 | 0 不是特徵值 | 行（列）線性獨立
cap: 一個成立，全部成立
```

$n\times n$ 矩陣 $A$ **可逆**：存在 $A^{-1}$ 使得 $AA^{-1}=A^{-1}A=I$。這時 $Ax=b$ 的解就是 $x=A^{-1}b$，唯一。

不可逆的叫**奇異矩陣**。

?? 選擇 | $A$ 可逆時，$Ax=b$ 有幾個解？
[x] 剛好一個
[ ] 可能無限多個
[ ] 可能沒有
!! 兩邊同乘 $A^{-1}$。
>> $x=A^{-1}b$，唯一。

**求反矩陣**：把 $[A\mid I]$ 消成 $[I\mid A^{-1}]$。消不出 $I$（某一行沒有 pivot）就是不可逆。

$2\times2$ 有公式：
$$\begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1}=\frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}$$
$ad-bc=0$ 時不可逆。

?? 填空 | $\begin{bmatrix}2&1\\5&3\end{bmatrix}^{-1}$ 的左上角是多少？
== 3
!! $ad-bc=6-5=1$。
>> $\frac11\begin{bmatrix}3&-1\\-5&2\end{bmatrix}$，左上角 3。

**可逆矩陣定理**（$A$ 是 $n\times n$，以下全部等價，一個成立就全部成立）：
- $A$ 可逆
- 消完每一行都有 pivot（RREF 是 $I$）
- $Ax=0$ 只有 $x=0$ 這個解
- $Ax=b$ 對每個 $b$ 都有唯一解
- $A$ 的行向量都「用得上」（沒有一行是其他行的組合）
- $A^T$ 可逆

（之後還會加上「行列式不是 0」「0 不是特徵值」。）

?? 選擇 | $3\times3$ 矩陣 $A$，$Ax=0$ 有一個非零解 $x=(1,1,0)$。下面哪一句對？
[ ] $A$ 可逆
[x] $A$ 不可逆，而且 $Ax=b$ 不可能對每個 $b$ 都有唯一解
[ ] 資訊不夠
!! 「$Ax=0$ 只有零解」是可逆的等價條件之一。
>> 有非零解，所以不可逆；等價條件全部一起不成立。

兩個常用性質：$(AB)^{-1}=B^{-1}A^{-1}$（順序反過來），$(A^T)^{-1}=(A^{-1})^T$。

?? 寫 | 在手寫板寫出：為什麼 $(AB)^{-1}=B^{-1}A^{-1}$？（驗證乘起來是 $I$）
== $(AB)(B^{-1}A^{-1})=A(BB^{-1})A^{-1}=AIA^{-1}=AA^{-1}=I$
!! 用結合律，讓 $B$ 和 $B^{-1}$ 先碰在一起。
>> 中間的 $BB^{-1}$ 先消掉，所以順序一定要反過來。

@例題 用 $[A\mid I]$ 求 $A=\begin{bmatrix}1&2\\3&7\end{bmatrix}$ 的反矩陣。
@寫 寫出 $[A\mid I]$，用第 1 列消掉第 2 列的 3 | $\begin{bmatrix}1&2&1&0\\0&1&-3&1\end{bmatrix}$
@寫 用第 2 列消掉第 1 列的 2 | 第 1 列減 2 倍第 2 列：$\begin{bmatrix}1&0&7&-2\\0&1&-3&1\end{bmatrix}$
@步 用公式驗算 | $ad-bc=7-6=1$，$A^{-1}=\begin{bmatrix}7&-2\\-3&1\end{bmatrix}$ ✓
@答 $A^{-1}=\begin{bmatrix}7&-2\\-3&1\end{bmatrix}$

=== la-systems#3
title: LU 分解：把消去法存起來
mins: 35
goal: 會從消去的乘數寫出 $L$、$U$；知道什麼時候要換列（$PA=LU$）；知道 LU 的用處
---
> [!先記住]
> 消去法做的事可以寫成 $A=LU$：$U$ 是消完的上三角矩陣；$L$ 是下三角、對角線是 1，裡面存著**每一步的乘數**。之後換一個 $b$，只要解兩個三角系統，不用重做消去。

```fig
flow: Ax = b -> A = LU -> 先解 Lc = b（往下代） -> 再解 Ux = c（往回代）*
```

高斯消去其實是把 $A$ 拆成兩個三角矩陣：
$$A=LU$$
- $U$：消完的**上三角**矩陣
- $L$：**下三角**，對角線是 1，對角線下面存**消去時用的乘數**

「第 $i$ 列減掉 $\ell_{ij}$ 倍的第 $j$ 列」，就把 $\ell_{ij}$ 放在 $L$ 的第 $i$ 列第 $j$ 行。

?? 選擇 | 消去時「第 2 列減掉 3 倍的第 1 列」。$L$ 的哪一格是 3？
[x] 第 2 列第 1 行
[ ] 第 1 列第 2 行
[ ] 第 2 列第 2 行
!! 對第 2 列做事、用的是第 1 列。
>> $\ell_{21}=3$。$L$ 的對角線都是 1。

例：$A=\begin{bmatrix}2&1\\6&8\end{bmatrix}$。第 2 列減 3 倍第 1 列：$U=\begin{bmatrix}2&1\\0&5\end{bmatrix}$，$L=\begin{bmatrix}1&0\\3&1\end{bmatrix}$。驗算 $LU=A$ ✓。

?? 填空 | $A=\begin{bmatrix}1&2\\4&9\end{bmatrix}=LU$，$U$ 的右下角是多少？
== 1
!! 第 2 列減 4 倍第 1 列。
>> $9-4\times2=1$，$U=\begin{bmatrix}1&2\\0&1\end{bmatrix}$、$L=\begin{bmatrix}1&0\\4&1\end{bmatrix}$。

**為什麼要 LU？** 同一個 $A$、很多個不同的 $b$ 時，分解一次（約 $n^3/3$ 次乘法），之後每個 $b$ 只要：
1. 解 $Ly=b$（往前代，$O(n^2)$）
2. 解 $Ux=y$（往回代，$O(n^2)$）

**要換列的時候**：消到某個 pivot 是 0，就必須跟下面的列交換。這時寫成 $PA=LU$，$P$ 是記錄換列的**排列矩陣**。

?? 選擇 | $A=\begin{bmatrix}0&1\\1&1\end{bmatrix}$ 能直接寫成 $A=LU$（不換列）嗎？
[ ] 可以
[x] 不行，第一個 pivot 是 0，要先換列
!! 第 1 列第 1 行是 0，能用它消掉下面嗎？
>> 0 消不了任何東西，要先交換兩列：$PA=LU$。

$A$ 對稱時可以寫成 $A=LDL^T$（$D$ 是對角矩陣，放 pivot），省一半工作。

?? 寫 | 在手寫板寫出：已經有 $A=LU$，要解 $Ax=b$，兩個步驟各解什麼？
== 先解 $Ly=b$（往前代）
== 再解 $Ux=y$（往回代）
!! $Ax=L(Ux)=b$，令 $Ux=y$。
>> 兩個三角系統都只要 $O(n^2)$。

@例題 求 $A=\begin{bmatrix}2&1&1\\4&3&3\\8&7&9\end{bmatrix}$ 的 LU 分解。
@寫 第一步：用第 1 列消第 2、3 列，記下乘數 | $\ell_{21}=2$、$\ell_{31}=4$；得到 $\begin{bmatrix}2&1&1\\0&1&1\\0&3&5\end{bmatrix}$
@寫 第二步：用第 2 列消第 3 列 | $\ell_{32}=3$；$U=\begin{bmatrix}2&1&1\\0&1&1\\0&0&2\end{bmatrix}$
@步 寫出 $L$ | $L=\begin{bmatrix}1&0&0\\2&1&0\\4&3&1\end{bmatrix}$
@答 $A=LU$，$L$ 存乘數 2、4、3；順便 $\det A=2\cdot1\cdot2=4$。

=== la-vs#1
title: 向量空間與子空間：三個條件
mins: 30
goal: 會用「含 0、加法封閉、乘法封閉」判斷子空間；認得常考的是／不是子空間
---
> [!先記住]
> **向量空間**：裡面的東西可以相加、可以乘上數，結果還在裡面。**子空間**：大空間裡的一部分，自己也是向量空間。檢查三件事：**有零向量、加起來還在、乘上數還在**。

```fig
plane
range: -2 3 -2 3
line 0 1 hl
line 1 1 bad
cap: 藍線過原點，是子空間；紅線不過原點，沒有零向量，不是子空間
```

**向量空間**：一群東西，可以相加、可以乘上一個數，而且結果還在裡面（加上一些理所當然的規則）。$\mathbb R^n$ 是最熟悉的例子；多項式、矩陣也都是。

**線性組合**：$c_1v_1+c_2v_2+\cdots+c_kv_k$。所有線性組合的集合叫 **span**$\{v_1,\dots,v_k\}$。

?? 選擇 | $\text{span}\{(1,0),(0,1)\}$ 是什麼？
[ ] 只有那兩個點
[ ] 一條線
[x] 整個平面 $\mathbb R^2$
!! $c_1(1,0)+c_2(0,1)=(c_1,c_2)$，能湊出哪些點？
>> 任何 $(a,b)$ 都能湊出來，就是整個平面。

**子空間**：向量空間裡的一部分，自己也是向量空間。判斷只要三件事：
1. **含零向量**
2. 兩個在裡面的相加，還在裡面
3. 在裡面的乘任何數，還在裡面

?? 選擇 | $\mathbb R^2$ 中的直線 $y=2x+1$ 是子空間嗎？
[ ] 是
[x] 不是
!! $(0,0)$ 在線上嗎？
>> $0\ne2\cdot0+1$，不含零向量。（$y=2x$ 就是子空間：過原點的直線。）

快速判斷法：**只要是「某個線性方程式 $=0$」的解集合，就是子空間**；「$=$ 非零的數」就不是。

- 是：$Ax=0$ 的解、對稱矩陣全體、上三角矩陣全體、次數 $\le n$ 的多項式、$\{f:f(0)=0\}$
- 不是：$Ax=b$（$b\ne0$）的解、可逆矩陣全體、次數**剛好** $n$ 的多項式、$\{f:f(0)=1\}$

?? 選擇 | 哪一個是 $2\times2$ 矩陣空間的子空間？
[x] 所有對稱矩陣
[ ] 所有可逆矩陣
[ ] 所有行列式等於 1 的矩陣
!! 零矩陣在不在裡面？
>> 零矩陣是對稱的；但零矩陣不可逆、行列式也不是 1。

?? 填空 | 「次數剛好是 2 的多項式」不是子空間：$x^2+x$ 和 $-x^2$ 相加，得到的多項式次數是多少？
== 1
!! 相加後 $x^2$ 消掉了。
>> $(x^2+x)+(-x^2)=x$，次數 1，跑出集合了，加法不封閉。

**兩個子空間的交集**一定是子空間；**聯集**通常不是（$x$ 軸 ∪ $y$ 軸：$(1,0)+(0,1)=(1,1)$ 不在裡面）。

?? 寫 | 在手寫板證明：$W=\{(x,y,z)\mid x+y+z=0\}$ 是 $\mathbb R^3$ 的子空間（三個條件各寫一行）。
== 含 0：$0+0+0=0$ ✓
== 加法：$u,v\in W$，$(u_1+v_1)+(u_2+v_2)+(u_3+v_3)=0+0=0$ ✓
== 乘法：$(cu_1)+(cu_2)+(cu_3)=c\cdot0=0$ ✓
!! 每個條件都代進 $x+y+z$ 算。
>> 三個條件都成立，所以是子空間（它是一個過原點的平面）。

@例題 判斷 $W=\{(a,b)\in\mathbb R^2\mid ab\ge0\}$（第一、三象限加上兩軸）是不是子空間。
@寫 含 0 嗎？乘法封閉嗎？ | $(0,0)$：$0\ge0$ ✓。$c(a,b)$：$c^2ab\ge0$ ✓。
@寫 加法封閉嗎？試一個例子 | $(1,0)+(0,-1)=(1,-1)$：$1\cdot(-1)=-1<0$ ✗。
@步 結論 | 三個條件要全部成立，加法不封閉，所以不是子空間。
@答 不是子空間（反例 $(1,0)+(0,-1)$）。

=== la-vs#2
title: 線性獨立、基底、維度
mins: 40
goal: 會判斷向量線性獨立；知道基底＝獨立＋張成；會算常見空間的維度
---
> [!先記住]
> **線性獨立**：沒有一個向量能用其他的組合出來（等價：$c_1v_1+\dots+c_kv_k=0$ 只有全部 $c=0$）。**基底**：獨立而且張成整個空間。**維度**＝基底裡有幾個向量，每組基底一樣多。

```fig
plane
range: -1 4 -1 4
vec (1,0) hl "v₁"
vec (1,2) hl "v₂"
vec (3,4) "v₃"
cap: v₁、v₂ 獨立，是 ℝ² 的基底。v₃ = (3, 4) = v₁ + 2v₂，加進來就不獨立了：ℝ² 裡最多 2 個獨立向量
```

**線性獨立**：$c_1v_1+\cdots+c_kv_k=0$ **只有** $c_1=\cdots=c_k=0$ 這個解。白話：**沒有一個向量是其他向量的組合**（每個都有新方向）。

判斷方法：把向量排成矩陣的行，消去，**每一行都有 pivot** 就獨立。

?? 選擇 | $(1,2)$ 和 $(2,4)$ 線性獨立嗎？
[ ] 獨立
[x] 相依
!! 一個是不是另一個的倍數？
>> $(2,4)=2(1,2)$，相依：$2v_1-v_2=0$。

先看影片：同一家咖啡店，換一組方向當尺，座標就變了。

@影片 la-vs 0-77.0

**基底**：一組向量，**線性獨立**而且**張成整個空間**。空間裡每個向量都能**唯一**寫成基底的組合，組合的係數就是**座標**。

**維度**：基底有幾個向量。（同一個空間的基底不唯一，但個數一定一樣。）

?? 填空 | $\mathbb R^4$ 的維度是多少？
== 4
!! 標準基底 $e_1,\dots,e_4$ 有幾個？
>> 4。

再看影片：要幾根才夠，還有考試陷阱。

@影片 la-vs 77.1-119.0

$\dim V=n$ 時的捷徑：
- $n$ 個獨立的向量**一定**是基底；$n$ 個張成的向量也一定是基底
- 超過 $n$ 個一定相依；少於 $n$ 個一定張不滿

?? 選擇 | $\mathbb R^3$ 裡的 4 個向量，一定怎樣？
[ ] 一定是基底
[x] 一定線性相依
[ ] 一定張成 $\mathbb R^3$
!! 3 維空間最多容得下幾個獨立的向量？
>> 超過維度一定相依。（張不張成不一定：4 個都在同一條線上就張不滿。）

常考的維度：
- 次數 $\le n$ 的多項式 $P_n$：$n+1$（基底 $1,x,\dots,x^n$）
- $n\times n$ 矩陣：$n^2$
- $n\times n$ 對稱矩陣：$\frac{n(n+1)}2$（對角線和上半部可以自由選）
- 反對稱矩陣：$\frac{n(n-1)}2$

?? 填空 | $3\times3$ 對稱矩陣全體的維度是多少？
== 6
!! 對角線 3 個，加上對角線上方 3 個。
>> $\frac{3\cdot4}2=6$。

**兩個子空間的維度**：$\dim(U+W)=\dim U+\dim W-\dim(U\cap W)$——跟集合的「交集算兩次要減掉」一樣。

?? 寫 | 在手寫板判斷 $(1,0,1)$、$(0,1,1)$、$(1,1,2)$ 是不是 $\mathbb R^3$ 的基底，寫出理由。

>> 3 個向量相依，張不滿 $\mathbb R^3$（只張成一個平面）。

=== la-systems#4
title: 四個基本子空間
mins: 40
goal: 會寫出 $C(A)$、$N(A)$、$C(A^T)$、$N(A^T)$ 各在哪、維度多少、怎麼找基底；知道哪兩對互相垂直
---
> [!先記住]
> 每個 $m\times n$、秩 $r$ 的矩陣都有四個子空間：**行空間** $C(A)$ 和**左零空間** $N(A^T)$ 在 $\mathbb R^m$，**列空間** $C(A^T)$ 和**零空間** $N(A)$ 在 $\mathbb R^n$。維度分別是 $r$、$m-r$、$r$、$n-r$，而且**兩兩垂直**。

```fig
flow: ℝⁿ -> 列空間 C(Aᵀ)：r 維* | 零空間 N(A)：n − r 維
flow: ℝᵐ -> 行空間 C(A)：r 維* | 左零空間 N(Aᵀ)：m − r 維
cap: 同一個空間裡的兩個子空間互相垂直，維度加起來剛好是整個空間
```

$m\times n$ 矩陣 $A$，pivot 有 $r$ 個（$r$ 叫做**秩** rank）。它帶著四個子空間：

| 子空間 | 是什麼 | 住在 | 維度 |
|---|---|---|---|
| 行空間 $C(A)$ | 行向量的所有組合（所有可能的 $Ax$） | $\mathbb R^m$ | $r$ |
| 零空間 $N(A)$ | $Ax=0$ 的所有解 | $\mathbb R^n$ | $n-r$ |
| 列空間 $C(A^T)$ | 列向量的所有組合 | $\mathbb R^n$ | $r$ |
| 左零空間 $N(A^T)$ | $A^Ty=0$ 的所有解 | $\mathbb R^m$ | $m-r$ |

?? 填空 | $A$ 是 $3\times5$，秩 $r=2$。零空間 $N(A)$ 的維度是多少？
== 3
!! $n-r$，$n$ 是行數。
>> $5-2=3$：有 3 個自由變數。

為什麼 $N(A)$ 的維度是 $n-r$？$n$ 個變數裡，$r$ 個有 pivot，剩下 $n-r$ 個是自由變數，每個自由變數給一個基底向量。

**$Ax=b$ 有解** ⇔ $b\in C(A)$（$b$ 是 $A$ 的行的組合）。

?? 選擇 | $Ax=b$ 有解，等價於？
[x] $b$ 在 $A$ 的行空間 $C(A)$ 裡
[ ] $b$ 在 $N(A)$ 裡
[ ] $A$ 可逆
!! $Ax=x_1(\text{第1行})+\cdots+x_n(\text{第}n\text{行})$。
>> $Ax$ 就是行的組合，所以要 $b$ 是行的組合。不必可逆（可逆是「每個 $b$ 都唯一」）。

**怎麼找基底**（先消成 RREF）：
- $C(A^T)$：RREF 的非零列
- $N(A)$：每個自由變數設 1、其他自由變數設 0，解出來
- $C(A)$：**原本的** $A$ 裡、pivot 所在的那幾行（列運算會改變行空間，所以不能用 RREF 的行！）

?? 選擇 | 求 $C(A)$ 的基底時，要用哪個矩陣的 pivot 行？
[ ] RREF 的
[x] 原本 $A$ 的
!! 列運算會改變哪一個空間？
>> 列運算會改變行空間（但不改變列空間和零空間）。pivot 的**位置**不變，所以拿原矩陣的那幾行。

**垂直關係**：$N(A)\perp C(A^T)$——$Ax=0$ 就是說 $x$ 跟 $A$ 的每一列內積是 0。同理 $N(A^T)\perp C(A)$。

?? 寫 | 在手寫板寫出：為什麼 $N(A)$ 裡的每個向量都垂直於 $A$ 的每一列？
== $Ax=0$ 的第 $i$ 個分量就是「第 $i$ 列」和 $x$ 的內積。全部是 0，所以 $x$ 跟每一列都垂直，也跟列的所有組合垂直。
!! 把 $Ax$ 一格一格寫出來。
>> 所以 $N(A)$ 和 $C(A^T)$ 互相垂直，而且維度加起來是 $n$（互為正交補）。

@例題 $A=\begin{bmatrix}1&2&3\\2&4&7\end{bmatrix}$。求秩、四個子空間的維度、$N(A)$ 的基底。
@寫 消成列梯形 | 第 2 列減 2 倍第 1 列：$\begin{bmatrix}1&2&3\\0&0&1\end{bmatrix}$，pivot 在第 1、3 行，$r=2$。
@寫 四個維度 | $C(A)$：2；$N(A)$：$3-2=1$；$C(A^T)$：2；$N(A^T)$：$2-2=0$。
@寫 求 $N(A)$：自由變數是哪個？設 1 解出來 | $x_2$ 自由，設 $x_2=1$：$x_3=0$，$x_1=-2$。基底 $(-2,1,0)$。
@答 $r=2$；維度 2、1、2、0；$N(A)=\text{span}\{(-2,1,0)\}$。

=== la-systems#5
title: 秩的性質：常考的不等式
mins: 30
goal: 會用 $\text{rank}(AB)\le\min$、Sylvester、$\text{rank}(A^TA)=\text{rank}A$；認得秩 1 矩陣
---
> [!先記住]
> **秩**＝樞紐數＝獨立的行數＝獨立的列數。最重要的式子是**秩＋零空間維度＝行數**。相乘不會讓秩變大。

```fig
matrix: 1 2 ; 2 4 ; 3 6
name: A
cap: 每一行都是 (1, 2, 3) 的倍數，秩 1。秩 1 的矩陣都能寫成「一行 × 一列」：A = (1, 2, 3)ᵀ (1, 2)
```

上一節學過：**秩** $r$ ＝ pivot 的數量 ＝ 行空間的維度 ＝ 列空間的維度。所以
$$\text{rank}A=\text{rank}A^T$$

?? 選擇 | $5\times3$ 矩陣的秩最大可能是多少？
[ ] 5
[x] 3
[ ] 15
!! 秩 ≤ 列數，也 ≤ 行數。
>> $r\le\min(m,n)=3$。

乘法讓秩**只會變小或不變**：
$$\text{rank}(AB)\le\min(\text{rank}A,\ \text{rank}B)$$
原因：$AB$ 的每一行都是 $A$ 的行的組合，所以 $C(AB)\subseteq C(A)$。乘上**可逆**矩陣則秩不變。

?? 填空 | $A$ 秩 2、$B$ 秩 3，$AB$ 的秩最多是多少？
== 2
!! 取最小的。
>> $\le\min(2,3)=2$。

**Sylvester 不等式**（$A$ 是 $m\times n$、$B$ 是 $n\times p$）：
$$\text{rank}A+\text{rank}B-n\le\text{rank}(AB)$$
常用的推論：$AB=0$ ⇒ $\text{rank}A+\text{rank}B\le n$。

?? 選擇 | $A$、$B$ 都是 $4\times4$，$AB=0$，$\text{rank}A=3$。$\text{rank}B$ 最多是多少？
[x] 1
[ ] 3
[ ] 4
!! $\text{rank}A+\text{rank}B\le n=4$。
>> $\text{rank}B\le4-3=1$。（白話：$B$ 的每一行都在 $N(A)$ 裡，而 $N(A)$ 只有 1 維。）

其他常考：
- $\text{rank}(A+B)\le\text{rank}A+\text{rank}B$
- $\text{rank}(A^TA)=\text{rank}A$（$A^TAx=0$ 推得出 $\|Ax\|^2=0$）
- **秩 1** ⇔ $A=uv^T$（每一行都是同一個向量的倍數）

?? 選擇 | $A=\begin{bmatrix}0&1\\0&0\end{bmatrix}$，$\text{rank}(A^2)$ 是多少？
[x] 0
[ ] 1
[ ] 2
!! 先算 $A^2$。
>> $A^2=0$，秩 0；但 $\text{rank}A=1$。所以「$\text{rank}(A^2)=\text{rank}A$」不一定成立。

?? 寫 | 在手寫板寫出 $\begin{bmatrix}2&4\\3&6\end{bmatrix}$ 寫成 $uv^T$ 的樣子。
== $\begin{bmatrix}2\\3\end{bmatrix}\begin{bmatrix}1&2\end{bmatrix}$
!! 第二行是第一行的 2 倍。
>> 每一行都是 $(2,3)$ 的倍數，秩 1。

@例題 判斷：「$m<n$ 時，$Ax=b$ 一定有無限多解」對嗎？「$Ax=0$ 一定有非零解」呢？
@寫 $Ax=0$ 的情況 | $r\le m<n$，自由變數 $n-r\ge1$ 個，所以一定有非零解 ✓。
@寫 $Ax=b$ 的情況：舉反例 | $A=\begin{bmatrix}1&1\end{bmatrix}$ 不行（秩 1 = $m$ 總有解）。取 $A=\begin{bmatrix}1&1&1\\1&1&1\end{bmatrix}$、$b=(0,1)$：兩列矛盾，無解。
@步 結論 | 有解的話一定無限多；但可能根本無解。
@答 第一句錯（可能無解），第二句對。

=== la-vs#3
title: 線性變換：核、值域、rank–nullity
mins: 35
goal: 會判斷一個函數是不是線性變換；會找 kernel 和 range；會用 rank–nullity；知道一對一 ⇔ kernel 只有 0
---
> [!先記住]
> **線性變換** $T$：保持加法和純量乘法，$T(u+v)=T(u)+T(v)$、$T(cv)=cT(v)$。**核** $\ker T$＝被送到 0 的東西；**像**＝所有輸出。$\dim\ker T+\dim\text{像}=\dim(\text{定義域})$。

```fig
flow: 定義域 V -> T -> 像 Im T（維度 = 秩）
flow: 核 ker T（維度 = 零度） -> 全部被送到 0!
cap: 秩 ＋ 零度 ＝ dim V
```

**線性變換** $T:V\to W$：保持加法和純量乘法。
$$T(au+bv)=a\,T(u)+b\,T(v)$$
所以一定有 $T(0)=0$。每個矩陣 $A$ 都給一個線性變換 $T(x)=Ax$。

?? 選擇 | 哪一個是線性變換（$\mathbb R\to\mathbb R$）？
[x] $T(x)=3x$
[ ] $T(x)=3x+1$
[ ] $T(x)=x^2$
!! 先檢查 $T(0)$ 是不是 0。
>> $3x+1$ 的 $T(0)=1\ne0$；$x^2$ 的 $T(2x)=4x^2\ne2T(x)$。只有 $3x$ 是。

兩個重要的子空間：
- **kernel**（核）$\ker T=\{v\mid T(v)=0\}$：被送到 0 的東西。（矩陣的話就是 $N(A)$。）
- **range**（值域）$=\{T(v)\}$：所有可能的輸出。（矩陣的話就是 $C(A)$。）

**rank–nullity**：
$$\dim\ker T+\dim\text{range}\,T=\dim V$$
（就是矩陣的 $(n-r)+r=n$。）

?? 填空 | $T:\mathbb R^5\to\mathbb R^3$，range 是 2 維。$\ker T$ 是幾維？
== 3
!! 加起來是定義域的維度 5。
>> $5-2=3$。

**一對一** ⇔ $\ker T=\{0\}$。原因：$T(u)=T(v)$ ⇔ $T(u-v)=0$ ⇔ $u-v\in\ker T$。

定義域和值域維度**一樣**（有限維）時：一對一 ⇔ 映成 ⇔ 可逆（同構）。

?? 選擇 | $T:\mathbb R^3\to\mathbb R^2$ 有可能是一對一嗎？
[ ] 可能
[x] 不可能
!! range 最多幾維？那 kernel 至少幾維？
>> range ≤ 2 維，所以 kernel ≥ $3-2=1$ 維，有非零向量被送到 0，不是一對一。

**兩個有限維空間同構 ⇔ 維度一樣**。例如次數 ≤ 3 的多項式 $P_3$ 和 $\mathbb R^4$ 同構（$a+bx+cx^2+dx^3\leftrightarrow(a,b,c,d)$）。

?? 寫 | 在手寫板找出 $D:P_3\to P_3$、$D(p)=p'$（微分）的 kernel 和 range，並用 rank–nullity 檢查。
== kernel：常數多項式（微分是 0 的），1 維。
== range：次數 ≤ 2 的多項式 $P_2$，3 維。
== $1+3=4=\dim P_3$ ✓
!! 哪些多項式微分後是 0？微分後最高能到幾次？
>> 微分不是一對一（常數都被送到 0），所以也不是映成。

@例題 $T:\mathbb R^3\to\mathbb R^3$，$T(x,y,z)=(x+y,\ y+z,\ x+2y+z)$。找 $\ker T$ 的基底和 range 的維度。
@寫 寫出矩陣，消去 | $A=\begin{bmatrix}1&1&0\\0&1&1\\1&2&1\end{bmatrix}\to\begin{bmatrix}1&1&0\\0&1&1\\0&0&0\end{bmatrix}$，秩 2。

@步 range 的維度 | 秩 2，range 是 2 維；$1+2=3$ ✓。
@答 $\ker T=\text{span}\{(1,-1,1)\}$，range 2 維；$T$ 不是一對一。

> **內積** $u\cdot v=u^Tv$。$u\cdot v=0$ 就是**垂直（正交）**。$\|v\|=\sqrt{v\cdot v}$ 是長度。**列空間和零空間互相垂直**：$Ax=0$ 就是說 $x$ 跟 $A$ 的每一列內積都是 0。

**內積** $u\cdot v=u^Tv=u_1v_1+\cdots+u_nv_n$。
- **長度**（範數）$\|v\|=\sqrt{v\cdot v}$
- **夾角**：$\cos\theta=\dfrac{u\cdot v}{\|u\|\|v\|}$
- **正交**（垂直，$u\perp v$）：$u\cdot v=0$

[ ] 只有零向量

=== la-ortho#5
title: Gram–Schmidt 與 QR 分解
mins: 35
goal: 會用 Gram–Schmidt 把一組獨立向量變成正交（單位）向量；知道它就是 $A=QR$；知道最小平方可以用 $R\hat x=Q^Tb$ 解
---
> [!先記住]
> **Gram–Schmidt** 把一組獨立的向量變成**正交單位**的向量：每次拿下一個向量，**扣掉它在前面那些方向上的投影**，剩下的部分就跟前面全部垂直，再除以長度。寫成矩陣就是 $A=QR$，$R$ 是上三角。

```fig
flow: 拿下一個 aₖ -> 扣掉在 q₁…qₖ₋₁ 上的投影 -> 除以長度 -> 得到 qₖ*
```

有一組獨立的向量 $a_1,a_2,\dots$，想要**同一個空間**的一組**正交**基底。

**Gram–Schmidt**：一個一個來，每個新向量**減掉它在前面那些方向上的投影**：
$$v_1=a_1,\quad v_2=a_2-\frac{v_1^Ta_2}{v_1^Tv_1}v_1,\quad v_3=a_3-\frac{v_1^Ta_3}{v_1^Tv_1}v_1-\frac{v_2^Ta_3}{v_2^Tv_2}v_2$$
最後各自除以長度，變成單位向量 $q_i$。

?? 選擇 | Gram–Schmidt 的每一步在做什麼？
[x] 減掉在前面所有方向上的投影，剩下垂直的部分
[ ] 把向量變成單位長度
[ ] 交換向量的順序
!! 怎樣讓 $v_2$ 跟 $v_1$ 垂直？
>> 拿掉 $a_2$ 在 $v_1$ 上的影子，剩下的就垂直了。

?? 寫 | 在手寫板對 $a_1=(1,1)$、$a_2=(1,0)$ 做 Gram–Schmidt，並正規化。
== $v_1=(1,1)$；$v_2=(1,0)-\frac12(1,1)=(\frac12,-\frac12)$
== $q_1=\frac1{\sqrt2}(1,1)$，$q_2=\frac1{\sqrt2}(1,-1)$
!! $\frac{v_1^Ta_2}{v_1^Tv_1}=\frac12$。
>> 驗算 $v_1\cdot v_2=\frac12-\frac12=0$ ✓。

**QR 分解**：把 Gram–Schmidt 的過程寫成矩陣：
$$A=QR$$
$Q$ 的各行是 $q_i$（正交單位），$R$ 是**上三角**（因為 $a_k$ 只用到 $q_1,\dots,q_k$），對角線是正的。$R=Q^TA$。

?? 選擇 | QR 分解中，$R$ 為什麼是上三角？
[x] 第 $k$ 個 $a_k$ 只用 $q_1$ 到 $q_k$ 就能組出來
[ ] 因為 $Q$ 是正交矩陣
[ ] 剛好而已
!! $a_1$ 用到 $q_2$ 了嗎？
>> $a_1$ 只跟 $q_1$ 有關，$a_2$ 跟 $q_1,q_2$ 有關……

**用 QR 解最小平方**：$A^TA\hat x=A^Tb$ 變成 $R^TQ^TQR\hat x=R^TQ^Tb$ ⇒
$$R\hat x=Q^Tb$$
上三角，往回代就好；數值上也比正規方程穩定。

?? 選擇 | $A=QR$ 時，最小平方解滿足？
[x] $R\hat x=Q^Tb$
[ ] $Q\hat x=Rb$
[ ] $\hat x=Q^Tb$
!! 把 $A=QR$ 代進正規方程，用 $Q^TQ=I$。
>> 再兩邊消掉可逆的 $R^T$。

@例題 對 $a=(1,-1,0)$、$b=(2,0,-2)$、$c=(3,-3,3)$ 做 Gram–Schmidt（先不正規化）。
@寫 第一、二個 | $A=a$；$B=b-\frac{a^Tb}{a^Ta}a=(2,0,-2)-\frac22(1,-1,0)=(1,1,-2)$
@寫 第三個 | $C=c-\frac{a^Tc}{a^Ta}a-\frac{B^Tc}{B^TB}B=(3,-3,3)-3(1,-1,0)+1\cdot(1,1,-2)=(1,1,1)$
@步 檢查 | $A\cdot B=0$、$A\cdot C=0$、$B\cdot C=0$ ✓；長度 $\sqrt2,\sqrt6,\sqrt3$
@答 $(1,-1,0)$、$(1,1,-2)$、$(1,1,1)$，再各除以長度。

> 任何 $m\times n$ 矩陣都能寫成 $A=U\Sigma V^T$：$V$、$U$ 是正交矩陣（旋轉），$\Sigma$ 是對角的（沿座標軸拉伸）。對角線上的**奇異值** $\sigma_1\ge\sigma_2\ge\dots\ge0$ 是 $A^TA$ 特徵值的平方根。

```fig
flow: x -> Vᵀ：轉 -> Σ：沿軸拉 σ₁、σ₂ 倍 -> U：再轉 -> Ax*
cap: 單位圓經過 A，變成主軸長 σ₁、σ₂ 的橢圓
```

特徵分解只對（某些）方陣有用。**SVD** 對**任何** $m\times n$ 矩陣都成立：
$$A=U\Sigma V^T$$
- $V$（$n\times n$ 正交）：各行是 $A^TA$ 的單位特徵向量
- $\Sigma$（$m\times n$ 對角）：**奇異值** $\sigma_1\ge\sigma_2\ge\cdots\ge0$，$\sigma_i=\sqrt{\lambda_i(A^TA)}$
- $U$（$m\times m$ 正交）：$u_i=Av_i/\sigma_i$

意思：任何矩陣＝**旋轉 → 各軸伸縮 → 再旋轉**。

[x] $A^TA$ 特徵值的平方根

[ ] $A$ 的對角線

>> 所以奇異值都是非負實數。

讀 SVD：
- **秩**＝非零奇異值的個數
- $\|A\|_2=\sigma_1$（最大的放大倍率）
- **最佳秩 $k$ 近似**（Eckart–Young）：只留前 $k$ 項 $\sum_{i\le k}\sigma_iu_iv_i^T$，誤差 $\sigma_{k+1}$
- **條件數** $\sigma_{\max}/\sigma_{\min}$：越大，解方程越不穩定

?? 填空 | 一個 $5\times4$ 矩陣的奇異值是 7、3、0、0。它的秩是多少？
== 2
!! 數非零的。
>> 秩 2。

**偽逆** $A^+=V\Sigma^+U^T$（$\Sigma^+$：非零的 $\sigma$ 取倒數、再轉置）。$x^+=A^+b$ 是最小平方解裡**長度最小**的那一個。

?? 選擇 | 「奇異值就是特徵值的絕對值」對嗎？
[ ] 對
[x] 不一定，對稱（正規）矩陣才是
!! 剛剛的例子：特徵值 3、5，奇異值 $3\sqrt5$、$\sqrt5$。
>> 對稱矩陣 $\sigma_i=|\lambda_i|$。

@例題 $A=\begin{bmatrix}1&1\\1&1\\0&0\end{bmatrix}$。求奇異值、秩，以及最佳秩 1 近似的誤差。
@寫 $A^TA$ 和特徵值 | $A^TA=\begin{bmatrix}2&2\\2&2\end{bmatrix}$，特徵值 4、0
@寫 奇異值和秩 | $\sigma_1=2$、$\sigma_2=0$；秩 1
@步 最佳秩 1 近似 | 它本身就是秩 1，誤差 $\sigma_2=0$
@答 奇異值 2、0；秩 1；秩 1 近似就是 $A$ 自己。
