=== al-recurrence#1
title: 漸近符號：O、Ω、Θ 是在比「長法」
mins: 35
goal: 會判斷 $f=O(g)$、$\Omega(g)$、$\Theta(g)$；會用極限比兩個函數
---
> [!先記住]
> 漸近符號只看 $n$ 很大時「誰長得快」，不管常數。$O$ 像 $\le$，$\Omega$ 像 $\ge$，$\Theta$ 像 $=$，$o$ 像 $<$，$\omega$ 像 $>$。

```fig
flow: 1 -> lg lg n -> lg n -> √n
flow: n -> n lg n -> n²
flow: 2ⁿ -> n!*
cap: 由小到大。n = 1024 時：lg n = 10、√n = 32、n² 約一百萬，2ⁿ 有三百多位數
```

上一個單元用「數步數」比程式快慢。但步數常常是 $3n^2+5n+7$ 這種式子，我們只想知道「它跟 $n^2$ 同一種長法」。漸近符號就是用來說這件事的：

- $f=O(g)$：$f$ **最多**跟 $g$ 一樣快長（像「$\le$」）
- $f=\Omega(g)$：$f$ **至少**跟 $g$ 一樣快長（像「$\ge$」）
- $f=\Theta(g)$：兩個都成立，**一樣的長法**（像「$=$」）

?? 選擇 | $3n^2+5n+7$ 跟哪一個是 $\Theta$（同一種長法）？
[ ] $n$
[x] $n^2$
[ ] $n^3$
!! 最高次那一項決定長法；係數不算。
>> 最高次是 $3n^2$，去掉係數就是 $n^2$。它也是 $O(n^3)$（最多跟 $n^3$ 一樣快），但不是 $\Theta(n^3)$。

正式定義（考試要會寫）：$f=O(g)$ 是說**存在**常數 $c>0$ 和 $n_0$，讓**所有** $n\ge n_0$ 都有 $f(n)\le c\cdot g(n)$。白話：$n$ 夠大以後，$g$ 乘上一個固定倍數就壓得住 $f$。

例：$3n^2+5n+7\le 3n^2+5n^2+7n^2=15n^2$（$n\ge1$），取 $c=15$、$n_0=1$，所以 $3n^2+5n+7=O(n^2)$。

?? 填空 | 要證明 $2n+10=O(n)$：$n\ge10$ 時 $2n+10\le c\cdot n$，$c$ 最小可以取多少？
== 3
!! $n\ge10$ 時，$10\le n$。
>> $2n+10\le2n+n=3n$，所以 $c=3$ 就夠（$n_0=10$）。

**用極限判斷最快**：算 $\lim_{n\to\infty}\frac{f(n)}{g(n)}$。
- 是 0：$f$ 長得比較慢，$f=O(g)$ 但不是 $\Theta$（這叫 $f=o(g)$，小 o）
- 是正的常數：$f=\Theta(g)$
- 是無限大：$f=\Omega(g)$ 但不是 $\Theta$

?? 選擇 | $f=n^2$、$g=n^2+n$，$\lim\frac fg$ 是多少？所以兩者是什麼關係？
[ ] 0，$f=o(g)$
[x] 1，$f=\Theta(g)$
[ ] 無限大，$f=\Omega(g)$
!! 分子分母都除以 $n^2$。
>> $\frac{n^2}{n^2+n}=\frac{1}{1+1/n}\to1$，是正的常數，所以 $\Theta$。

兩個常考的陷阱：
- $2^{n+1}=2\cdot2^n$，只差常數倍，所以 $2^{n+1}=\Theta(2^n)$。
- $2^{2n}=(2^n)^2$，比 $2^n$ 多乘了一個 $2^n$，**不是** $O(2^n)$。

指數裡的常數**加**沒關係，**乘**就差很多。

?? 選擇 | 哪一個**不是** $O(2^n)$？
[ ] $2^{n+5}$
[ ] $n^{10}$
[x] $4^n$
[ ] $2^n+n^2$
!! $4^n=(2^2)^n=2^{2n}$。
>> $4^n/2^n=2^n\to\infty$，所以 $4^n$ 不是 $O(2^n)$。$2^{n+5}=32\cdot2^n$ 只差常數；$n^{10}$ 比指數慢。

對數在漸近裡也很常出現：$\log_2 n$、$\log_{10} n$ 只差一個常數倍（換底公式），所以寫 $O(\lg n)$ 時**底數不用寫**。而 $\lg(n!)=\Theta(n\lg n)$ 是考試常客：$n!$ 有 $n$ 個因數，一半以上都 $\ge n/2$。

?? 排序 | 依長法從慢排到快
- $\lg n$
- $\sqrt n$
- $n$
- $n\lg n$
- $n^2$
- $2^n$
!! $\sqrt n=n^{0.5}$，比任何 $\lg n$ 都快、比 $n$ 慢。
>> $\lg n\prec n^{0.5}\prec n\prec n\lg n\prec n^2\prec 2^n$。任何正次方 $n^\varepsilon$ 最後都比 $\lg n$ 大。

@例題 判斷 $f(n)=n\lg n$ 和 $g(n)=n^{1.5}$ 的關係（$O$、$\Omega$、$\Theta$？）。
@寫 列出要算的極限，並約掉共同的部分 | $\lim\frac{n\lg n}{n^{1.5}}=\lim\frac{\lg n}{n^{0.5}}$
@步 判斷這個極限 | 分母是 $n$ 的正次方，長得比 $\lg n$ 快，所以極限是 0。（也可以用羅必達：$\frac{1/(n\ln2)}{0.5n^{-0.5}}\to0$。）
@寫 寫出結論 | 極限 0 → $f=o(g)$，所以 $f=O(g)$，但不是 $\Omega(g)$，也不是 $\Theta(g)$。
@答 $n\lg n=O(n^{1.5})$（而且是小 o），不是 $\Theta$。

=== al-recurrence#2
title: Master 定理：看「每往下一層，總工作變幾倍」
mins: 35
goal: 看到 $T(n)=aT(n/b)+f(n)$，30 秒內判斷是哪一種、寫出答案
---
> [!先記住]
> $T(n)=aT(n/b)+f(n)$：把問題切成 $a$ 個大小 $n/b$ 的子問題，切和合併花 $f(n)$。拿 $f(n)$ 跟 $n^{\log_b a}$（所有葉子的總工作量）比：誰大就是誰；一樣大就多乘一個 $\lg n$。

```fig
flow: 比 f(n) 和 n^(log_b a) -> f 小很多 | 差不多 | f 大很多 -> Θ(n^(log_b a)) | 多乘 lg n* | Θ(f(n))
cap: 小很多、大很多指的是差了 n^ε 倍（多項式倍）
```

很多遞迴程式長這樣：把大小 $n$ 的問題拆成 $a$ 個、每個大小 $n/b$，拆開和合併本身要花 $f(n)$ 步。寫成式子：
$$T(n)=a\,T(n/b)+f(n)$$
**合併排序**就是這樣：切兩半各自排好（$a=2$，$b=2$），再把兩半合併、要掃一遍（$f(n)=n$），所以 $T(n)=2T(n/2)+n$。

?? 選擇 | 二分搜尋每次只往一半找、比較一次花固定時間。它的遞迴式是？
[ ] $T(n)=2T(n/2)+1$
[x] $T(n)=T(n/2)+1$
[ ] $T(n)=T(n-1)+1$
!! 切成兩半之後，要往「幾半」繼續找？
>> 只往其中一半找，所以 $a=1$、$b=2$；每層多比較一次：$f(n)=1$。

先看影片：一家公司把工作一層一層往下拆，每一層一共花多少時間。

@影片 al-master 0-85.4

?? 填空 | $T(n)=2T(n/2)+n$：第 0 層的工作是 $n$；第 1 層有兩個 $n/2$，加起來是多少？
== n
== 1n
!! 兩個 $n/2$ 相加。
>> $n/2+n/2=n$。每一層都是 $n$，一共 $\lg n$ 層，所以總共 $n\lg n$。

關鍵只有一個數：**每往下一層，總工作變幾倍**。下一層的問題多了 $a$ 倍，但每個變小。若 $f(n)=n^d$，每個變成 $(n/b)^d$，所以下一層總共是這一層的
$$r=\frac{a}{b^d}\ \text{倍}$$
合併排序 $a=2$、$b=2$、$d=1$：$r=1$，每層一樣多。

?? 選擇 | $T(n)=4T(n/2)+n$，每往下一層，總工作變幾倍？
[ ] 1 倍
[x] 2 倍
[ ] 4 倍
[ ] $\frac12$ 倍
!! 用 $r=a/b^d$：$a=4$、$b=2$、$d=1$。
>> $4/2^1=2$。越往下越多，工作集中在最底下的葉子。

@影片 al-master 85.6-158.5

三種形狀，各對一個答案：
- $r>1$（越往下越多）：**葉子決定**，答案 $\Theta(n^{\log_b a})$
- $r=1$（每層一樣）：每層 $n^d$、共 $\log_b n$ 層 → $\Theta(n^d\lg n)$
- $r<1$（越往下越少）：**根決定**，答案 $\Theta(f(n))=\Theta(n^d)$

?? 排序 | 把判斷步驟排成正確順序
- 讀出 $a$、$b$、$d$
- 算 $r=a/b^d$
- 看 $r$ 比 1 大、等於 1、還是小於 1
- 寫出對應的答案
>> 每一題都照這四步，不用背表格。

@影片 al-master 158.7-207.0

?? 選擇 | $T(n)=2T(n/2)+n^2$ 的答案是？
[ ] $\Theta(n\lg n)$
[ ] $\Theta(n^2\lg n)$
[x] $\Theta(n^2)$
!! 先算 $r=a/b^d=2/2^2$。
>> $r=\frac12<1$，根決定，答案就是 $f(n)=n^2$。

為什麼葉子那一種是 $n^{\log_b a}$？樹有 $\log_b n$ 層，最底層有 $a^{\log_b n}$ 個葉子；換底以後就是 $n^{\log_b a}$（兩邊取 $\lg$ 會一樣）。例：$4T(n/2)$ 的葉子有 $4^{\lg n}=n^{\lg 4}=n^2$ 個。

?? 填空 | $T(n)=8T(n/2)+n^2$ 的答案是 $\Theta(\ ?\ )$（寫成 n^3 這種格式）
== n^3
== n³
!! $r=8/2^2=2>1$，葉子決定，答案是 $n^{\log_2 8}$。
>> $\log_2 8=3$，答案 $\Theta(n^3)$。

考試正式寫法要對上課本的三種情況（右邊「考試筆記」有完整的表）：**情況 1＝葉子決定、情況 2＝每層一樣、情況 3＝根決定**。情況 3 還要多寫一個 regularity 條件：$af(n/b)\le c\,f(n)$，$c<1$——意思就是「下一層比這一層少」，也就是 $r<1$。

@影片 al-master 207.2-244.9

?? 選擇 | $T(n)=3T(n/4)+n$ 是課本的第幾種情況？
[ ] 情況 1（葉子決定）
[ ] 情況 2（每層一樣）
[x] 情況 3（根決定）
!! $r=3/4^1$，比 1 大還是小？
>> $r=\frac34<1$，越往下越少，根決定，是情況 3，答案 $\Theta(n)$。

@例題 解 $T(n)=3T(n/4)+n^2$，寫出是哪一種情況和答案。
@寫 先讀出 $a$、$b$、$d$ | $a=3$，$b=4$，$f(n)=n^2$ 所以 $d=2$。
@寫 算每往下一層的倍率 $r$ | $r=a/b^d=3/4^2=\frac{3}{16}$。
@步 判斷形狀，並寫 regularity | $r<1$：越往下越少，根決定（情況 3）。regularity：$3\left(\frac n4\right)^2=\frac{3}{16}n^2\le c\,n^2$，取 $c=\frac3{16}<1$ 成立。
@答 $T(n)=\Theta(n^2)$

@例題 解 $T(n)=9T(n/3)+n$。
@寫 讀出 $a$、$b$、$d$，算 $r$ | $a=9$，$b=3$，$d=1$；$r=9/3=3$。
@寫 判斷形狀、寫出答案 | $r>1$，葉子決定（情況 1）：$\Theta(n^{\log_3 9})=\Theta(n^2)$。
@答 $T(n)=\Theta(n^2)$

=== al-recurrence#3
title: 遞迴樹：Master 套不上時，一層一層加
mins: 35
goal: 會畫遞迴樹、寫出每層成本、把每層加起來；認得 $n/\lg n$ 這種 Master 的縫隙
---
> [!先記住]
> 子問題大小不一樣時，Master theorem 不能用。畫**遞迴樹**：把各層工作量加總。只有各層成本同階時，才可用「每層 × 層數」。

```fig
tree
[n]([n/3]([n/9],[2n/9]),[2n/3]([2n/9],[4n/9]))
cap: T(n) = T(n/3) + T(2n/3) + n：前約 log₃ n 層完整、各層成本 n；其後每層至多 n，最深約 log₍₃/₂₎ n 層 → Θ(n lg n)
```

Master 定理只管「每個子問題一樣大」而且 $f$ 夠整齊的情況。套不上時，就回到最原始的做法：**畫出遞迴樹，一層一層把工作加起來**。

步驟只有三個：
1. 第 $i$ 層有幾個子問題？每個多大？
2. 這一層的總工作是多少？
3. 一共幾層？把每層加起來。

?? 選擇 | $T(n)=2T(n/2)+n$ 的第 $i$ 層（根是第 0 層）有幾個子問題？
[ ] $i$ 個
[ ] $2i$ 個
[x] $2^i$ 個
!! 每往下一層，每個問題變成 2 個。
>> 第 0 層 1 個、第 1 層 2 個、第 2 層 4 個……第 $i$ 層 $2^i$ 個，每個大小 $n/2^i$。

**兩邊不一樣大**的例子：$T(n)=T(n/3)+T(2n/3)+n$。每一層的子問題大小加起來還是 $n$，所以**每層都是 $n$**（下面幾層開始缺角，只會更少）。

最長的路一直走 $2n/3$ 那邊，要走 $\log_{3/2} n$ 層才到 1，所以總共 $O(n\lg n)$；最短的路走 $\log_3 n$ 層，每層都滿，所以也 $\Omega(n\lg n)$。答案 $\Theta(n\lg n)$。

?? 選擇 | $T(n)=T(n/3)+T(2n/3)+n$，為什麼每一層的總工作最多是 $n$？
[x] 這一層所有子問題的大小加起來不超過 $n$
[ ] 因為每層只有一個子問題
[ ] 因為 $\frac13+\frac23<1$
!! 第 1 層是 $\frac n3$ 和 $\frac{2n}3$，加起來多少？
>> $\frac n3+\frac{2n}3=n$；再往下也一樣，每一層的大小總和都是 $n$（底下缺角的層更少）。

**Master 的縫隙**：$T(n)=2T(n/2)+\frac{n}{\lg n}$。$f=\frac{n}{\lg n}$ 比 $n$ 小，但只小一個 $\lg n$——不是「小一個多項式倍」，課本的三種情況都套不上。

用遞迴樹：第 $i$ 層有 $2^i$ 個、每個大小 $\frac n{2^i}$，成本 $2^i\cdot\frac{n/2^i}{\lg(n/2^i)}=\frac{n}{\lg n-i}$。

?? 填空 | 把第 $i$ 層成本 $\frac{n}{\lg n-i}$ 從 $i=0$ 加到 $\lg n-1$。令 $j=\lg n-i$，變成 $n\left(\frac11+\frac12+\cdots+\frac1{\lg n}\right)$。括號裡是 $H_{\lg n}$，大約是 $\ln(\lg n)$。所以答案是 $\Theta(n\cdot\ ?\ )$？（寫 lglgn 或 lg lg n）
== lglgn
== lg lg n
== lglg n
== \lg\lg n
!! 調和級數 $H_m\approx\ln m$，這裡 $m=\lg n$。
>> $n\cdot H_{\lg n}=\Theta(n\lg\lg n)$。這是擴充版 Master 的 $k=-1$ 那一格。

?? 填空 | $T(n)=2T(n/2)+n^2$ 的遞迴樹：第 1 層（根的下一層）的總工作是多少？（寫成 n^2/幾，例如 n^2/4）
== n^2/2
== n²/2
!! 第 1 層有 2 個子問題，每個大小 $n/2$，每個的工作是 $(n/2)^2$。
>> $2\cdot\frac{n^2}4=\frac{n^2}2$，每層減半，總和被根的 $n^2$ 決定：$\Theta(n^2)$。

@例題 用遞迴樹解 $T(n)=4T(n/2)+n^2\lg n$。
@寫 寫出第 $i$ 層有幾個子問題、每個多大、這一層總成本 | 第 $i$ 層 $4^i$ 個，每個大小 $\frac n{2^i}$，成本 $4^i\cdot\left(\frac{n}{2^i}\right)^2\lg\frac n{2^i}=n^2(\lg n-i)$。
@步 一共幾層？把每層加起來 | 共 $\lg n$ 層：$\sum_{i=0}^{\lg n-1}n^2(\lg n-i)=n^2(\lg n+(\lg n-1)+\cdots+1)=n^2\cdot\frac{\lg n(\lg n+1)}2$。
@寫 寫出答案（只留最高次） | $\Theta(n^2\lg^2 n)$。
@答 $T(n)=\Theta(n^2\lg^2n)$（每層差不多大、慢慢變小，像一個三角形）。

=== al-recurrence#4
title: 變數變換：$T(\sqrt n)$ 先換成 $S(m)$
mins: 30
goal: 遇到 $T(\sqrt n)$ 或 $T(n-1)$ 這種不是「除以 $b$」的遞迴，會換變數或直接展開
---
> [!先記住]
> 看到 $\sqrt n$ 就令 $m=\lg n$：開根號在位數上就是除以 2，遞迴式會變回熟悉的樣子。看到 $T(n-1)$ 就直接展開加總。

```fig
flow: T(n)=2T(√n)+lg n -> 令 m = lg n -> S(m)=2S(m/2)+m
flow: S(m) = Θ(m lg m) -> T(n) = Θ(lg n · lg lg n)*
```

有些遞迴的子問題是 $\sqrt n$，像 $T(n)=2T(\sqrt n)+\lg n$。Master 定理要「$n/b$」，套不上。

技巧：令 $n=2^m$（也就是 $m=\lg n$），那 $\sqrt n=2^{m/2}$。再令 $S(m)=T(2^m)$：
$$S(m)=2S(m/2)+m$$
這就變回熟悉的樣子了。

?? 選擇 | 令 $n=2^m$，那 $\sqrt n$ 等於？
[ ] $2^{m-1}$
[x] $2^{m/2}$
[ ] $m/2$
!! $\sqrt{x}=x^{1/2}$。
>> $\sqrt{2^m}=(2^m)^{1/2}=2^{m/2}$。

$S(m)=2S(m/2)+m$ 是合併排序的形狀，$S(m)=\Theta(m\lg m)$。**最後別忘了換回來**：$m=\lg n$，所以
$$T(n)=\Theta(\lg n\cdot\lg\lg n)$$

?? 填空 | $T(n)=T(\sqrt n)+1$：換成 $S(m)=S(m/2)+1$，$S(m)=\Theta(\lg m)$。換回 $n$，$T(n)=\Theta(\ ?\ )$（寫 lglgn）
== lglgn
== lg lg n
== lglg n
!! $m=\lg n$，所以 $\lg m=\lg\lg n$。
>> $T(n)=\Theta(\lg\lg n)$：每次開根號，要開 $\lg\lg n$ 次才到常數。

另一種常見的：**減一**的遞迴，像 $T(n)=T(n-1)+n$。沒有「切一半」，就直接展開：
$$T(n)=n+(n-1)+(n-2)+\cdots+1=\frac{n(n+1)}2=\Theta(n^2)$$

?? 選擇 | $T(n)=T(n-1)+1$，$T(1)=1$ 的答案是？
[ ] $\Theta(1)$
[ ] $\Theta(\lg n)$
[x] $\Theta(n)$
[ ] $\Theta(n^2)$
!! 展開：$1+1+\cdots+1$ 共幾個？
>> 每次只少 1，要 $n$ 次才到底，每次花 1，所以 $\Theta(n)$。

**兩個 $T(n-1)$** 就很可怕：$T(n)=2T(n-1)+1$ 每往下一層翻倍，共 $n$ 層，是 $\Theta(2^n)$（河內塔就是這個）。

?? 選擇 | $T(n)=2T(n-1)+1$ 的答案是？
[ ] $\Theta(n)$
[ ] $\Theta(n^2)$
[x] $\Theta(2^n)$
!! 每往下一層，子問題變成幾個？一共幾層？
>> 第 $i$ 層有 $2^i$ 個，共 $n$ 層，總共 $1+2+\cdots+2^{n-1}=2^n-1$。

**分治法**（divide and conquer）：
1. **切**（divide）：把問題切成幾個小一點的同類問題
2. **遞迴**（conquer）：小問題用同樣方法解；夠小就直接算
3. **合併**（combine）：把小問題的答案組合成大問題的答案

合併排序就是標準範例：切兩半、各自排、合併。

- 合併：把兩個排好的半邊合成一個

1. 依 $x$ 座標排好，用中線切成左右兩半。
2. 遞迴找左邊最近的 $\delta_L$、右邊最近的 $\delta_R$，令 $\delta=\min(\delta_L,\delta_R)$。

title: FFT：多項式乘法從 n² 變 n lg n
mins: 40
goal: 知道 FFT 多項式乘法的三步（求值、逐點相乘、內插）；知道單位根讓問題能對半切

> [!先記住]
> 兩個 $n$ 次多項式直接相乘要 $\Theta(n^2)$。換個表示法：先在 $2n$ 個特別的點上**求值**，點值兩兩相乘，再**變回係數**。用 FFT 在「單位根」上求值和變回去，都只要 $O(n\lg n)$。

```fig
flow: 係數 -> FFT 求值：O(n lg n) -> 逐點相乘：O(n)
flow: 逆 FFT：O(n lg n) -> 乘積的係數*
```

兩個 $n$ 次多項式相乘，係數一個一個乘：$\Theta(n^2)$。FFT 的想法是**換一種表示法**。

一個 $n-1$ 次多項式，可以用**係數**表示，也可以用**它在 $n$ 個點的值**表示（$n$ 個點決定一個 $n-1$ 次多項式）。

**用點值表示時，相乘超簡單**：同一個點的值相乘就好，$O(n)$。

?? 選擇 | $A(x)=1+x$、$B(x)=2-x$。在 $x=3$ 這點，$C=AB$ 的值是？
[x] $-4$
[ ] $5$
[ ] $1$
!! $A(3)=4$、$B(3)=-1$。
>> $C(3)=A(3)\cdot B(3)=-4$。直接算 $C(x)=2+x-x^2$，$C(3)=2+3-9=-4$ ✓。

所以多項式乘法變成三步：
1. **求值**：算 $A$、$B$ 在 $2n$ 個點的值（結果是 $2n-1$ 次，要夠多點）
2. **逐點相乘**：$O(n)$
3. **內插**：從點值變回係數

?? 排序 | FFT 多項式乘法的三步

- 逐點相乘
- 內插：用反 FFT 變回係數
>> 第 1、3 步各 $\Theta(n\lg n)$，第 2 步 $\Theta(n)$。

把 $A(x)$ 拆成偶數次項、奇數次項：
$$A(x)=A_{\text{偶}}(x^2)+x\,A_{\text{奇}}(x^2)$$
在 $n$ 個單位根求值，只要遞迴算兩個**一半大小**的問題：
$$T(n)=2T(n/2)+\Theta(n)=\Theta(n\lg n)$$

== 1, 3

[x] 單位根平方後點數減半，才能一直對半遞迴
[ ] 單位根算起來比較精確
[ ] 隨便挑點也一樣快

>> $n$ 個單位根平方只剩 $n/2$ 個不同的值，子問題變一半。隨便挑的點平方後還是 $n$ 個。

> [!先記住]
> 表格除了存最佳值，還要記「這格是從哪來的」；從答案那格往回走，就能拼出完整的解。只要最佳值時，常常只留兩列就夠。

```fig

pivot: 2,2 3,4 4,3
```

DP 表的右下角給的是「最佳的**值**」。要知道**最佳解是什麼**（哪些字、哪些物品），有兩種做法：
- 填表時順便記下「這格是從哪一格來的」（箭頭）
- 或者填完之後，從答案那格**倒著走**，每一步看它是從哪個選擇來的

這叫**重建解**。

?? 選擇 | LCS 表倒著走時，遇到 $x_i=y_j$ 的格子要怎麼做？

[ ] 往上走
[ ] 往左走

?? 寫 | 在手寫板：背包例題（容量 5，物品 (2,3)、(3,4)、(4,5)）最後 $K[3,5]=7$、$K[2,5]=7$、$K[1,2]=3$。倒推出拿了哪些物品。

== $K[2,5]=7\ne K[1,5]=3$：拿了第 2 個，剩容量 2，看 $K[1,2]=3\ne0$：拿了第 1 個
!! 值跟上一列一樣，就是沒拿。
>> 拿第 1、2 個。

**省空間**：如果只要值、不用重建，很多 DP 只需要「上一列」：
- LCS 只要長度：保留兩列，空間 $O(\min(m,n))$


[ ] 程式會當掉

=== al-dp#4
title: 偽多項式：$O(nW)$ 為什麼不算多項式時間
mins: 25
goal: 知道「多項式時間」是相對於輸入的位元數；說得出 $O(nW)$ 為什麼是偽多項式；能判斷一個時間是不是偽多項式
---
> [!先記住]
> **0/1 背包**：$K[i,w]$＝只用前 $i$ 個物品、容量 $w$ 時的最大價值，$O(nW)$。這個時間看起來是多項式，其實是**偽多項式**：$W$ 只要 $\lg W$ 個位元就寫得下，$nW$ 對輸入長度是指數。

```fig
array
row 金額: 0 1 2 3 4 5 6
row 最少枚數: 0 1 2 1 1 2 2*
cap: M[6] = 1 + min(M[5], M[3], M[2]) = 1 + 1 = 2（3 + 3）
```

「多項式時間」的意思是：時間是**輸入長度**的多項式。輸入長度＝寫下輸入要幾個**位元**。

一個數字 $W$ 只要 $\lg W$ 個位元就寫得下。

?? 填空 | $W=1{,}000{,}000$，用二進位寫大約要幾個位元？
== 20
!! $2^{10}\approx1000$。
>> $2^{20}\approx10^6$，大約 20 個位元。

背包的時間 $O(nW)$：
- 輸入長度大約是 $n\lg W$（$n$ 個物品，每個數字 $\lg W$ 位元）
- 但時間跟 $W$ **本身**成正比
- $W=2^{\lg W}$：對位元數來說是**指數**

這種「對數值是多項式、對位元數是指數」的時間，叫**偽多項式**（pseudo-polynomial）。

?? 選擇 | 背包的 $W$ 多一個位元（例如從 20 位元變 21 位元），$O(nW)$ 的時間大約會？
[ ] 多一點點
[x] 變兩倍
[ ] 不變
!! 多一個位元，$W$ 最大可以變多大？
>> $W$ 可以翻倍，時間也翻倍。每多一個位元就翻倍＝指數。

?? 選擇 | 下面哪一個是偽多項式時間？（$n$ 是個數，$W$ 是輸入裡的一個數值）
[x] $O(nW)$
[ ] $O(n^2)$
[ ] $O(n\lg W)$
!! 哪一個直接跟 $W$ 的數值成正比？
>> $O(n\lg W)$ 是真的多項式（$\lg W$ 就是位元數）。

所以 0/1 背包**沒有**已知的多項式時間演算法（之後學 NP 時會知道它是難問題）。但如果把物品切開可以拿一部分（**分數背包**），照「每單位重量的價值」從高到低拿就好，$O(n\lg n)$。

?? 寫 | 在手寫板說明：「0/1 背包有 $O(nW)$ 的 DP，所以它是多項式時間可解的」錯在哪裡？
== 多項式時間要看輸入的位元數；$W$ 只佔 $\lg W$ 位元。
== $O(nW)=O(n\cdot2^{\lg W})$，對位元數是指數，所以只是偽多項式。
!! 輸入長度裡，$W$ 佔了多少？
>> 這是考試很愛考的觀念題。

@例題 用試除法判斷 $N$ 是不是質數（從 2 試到 $\sqrt N$），時間 $O(\sqrt N)$。這是多項式時間嗎？

@步 結論 | 對 $b$ 是指數，所以是偽多項式，不是多項式時間。

title: 貪婪法：每步選眼前最好的，但要證明

> [!先記住]
> **貪婪法**：每一步都挑「眼前看起來最好的」，挑了就不回頭。它很快，但不一定對。要證明對，標準做法是**交換論證**：拿任何一個最佳解，把它的第一步換成貪婪的選擇，證明不會變差。

```fig
flow: 任一個最佳解 O -> 把 O 的第一步換成貪婪的選擇
flow: 還是合法、而且沒變差 -> 存在一個最佳解包含貪婪的選擇*
```

**貪婪法**（greedy）：每一步都選**當下看起來最好**的，選了就不回頭。

很快、很簡單——但**常常是錯的**。所以一定要證明。要證兩件事：
1. **貪婪選擇性質**：存在某個最佳解，第一步跟貪婪選的一樣
2. **最佳子結構**：選完之後，剩下的子問題的最佳解，加上這一步，就是整體的最佳解

?? 選擇 | 貪婪法和 DP 最大的差別是？
[x] 貪婪先做選擇、只解一個子問題；DP 試過所有選擇再挑最好的
[ ] 貪婪一定比較慢
[ ] DP 不需要最佳子結構
!! 貪婪做選擇的時候，看過子問題的答案了嗎？
>> 貪婪不回頭，所以要證明「第一步這樣選不會錯」。

**交換論證**（證第 1 點最常用的方法）：
- 拿**任何一個**最佳解 $O$
- 如果 $O$ 的第一步跟貪婪的不一樣，把它**換成**貪婪的選擇
- 證明換完**不會變差**（而且還是合法的解）
- 所以「有一個最佳解是從貪婪的選擇開始」

?? 選擇 | 交換論證的第一步是？
[x] 拿任意一個最佳解
[ ] 先假設貪婪是錯的
[ ] 列出所有可能的解

>> 從任意最佳解出發，把它改造成包含貪婪選擇的、一樣好的解。

?? 寫 | 在手寫板用交換論證證明：從 $n$ 個正數裡挑 $k$ 個讓總和最大，每次挑最大的那個是對的。

=== al-greedy#5
title: 擬陣：貪婪一定對的結構
mins: 30
goal: 知道擬陣的兩個條件（遺傳性、交換性）；知道在擬陣上「照權重由大到小、能加就加」一定得到最佳；知道圖擬陣和 Kruskal 的關係；會用反例說明某個結構不是擬陣

> [!先記住]
> **擬陣（matroid）**是一種「挑子集合」的結構，只要滿足兩個條件，**照權重由大到小、能加就加**的貪婪法一定得到最佳解。最小生成樹的 Kruskal 就是一個例子。

```fig
graph
nodes: A@0,0 B@1,0 C@0,1 D@1,1
edges: A-B:1* C-D:2* A-C:3* B-D:4!
cap: Kruskal：選 1、2、3（藍）；4 的兩端 B、D 已經同一群（會成環），跳過
```

有沒有一種結構，**保證**貪婪一定對？有：**擬陣**（matroid）。

$M=(S,\mathcal I)$：$S$ 是有限集合，$\mathcal I$ 是一些「**獨立**」的子集，滿足：

title: 最短路徑的基本工具：鬆弛
mins: 30
goal: 知道 $\delta(s,v)$ 和 $v.d$ 的差別；會做鬆弛（relax）；知道三角不等式、上界性質、路徑鬆弛性質；知道負環讓最短路徑沒有定義

> [!先記住]
> **鬆弛（relax）** 邊 $(u,v)$：如果「先到 $u$ 再走這條邊」比目前記的 $v.d$ 還短，就更新 $v.d$。所有最短路徑演算法都在做鬆弛，差別只在**用什麼順序**鬆弛哪些邊。

```fig
graph
nodes: s*@0,1 u@1,0 v@2,1
edges: s>u:2 u>v:3* s>v:7
cap: 一開始 v.d = 7。鬆弛 (u, v)：u.d + 3 = 2 + 3 = 5 < 7，所以 v.d 改成 5，v 的前一站改成 u
```

有權重的圖，從起點 $s$ 到每個點 $v$ 的**最短路徑**權重記成 $\delta(s,v)$。演算法裡每個點有一個估計值 $v.d$（一開始 $s.d=0$、其他 $\infty$），慢慢改小。

**鬆弛**（relax）邊 $(u,v)$：「經過 $u$ 走過來會不會比較近？」
$$\text{若 }v.d>u.d+w(u,v)\text{，就令 }v.d=u.d+w(u,v)\text{，並記 }v.\pi=u$$

?? 填空 | $v.d=10$、$u.d=4$、$w(u,v)=3$。鬆弛 $(u,v)$ 之後 $v.d=$？
== 7
!! $4+3<10$ 嗎？
>> 更新成 7，$v$ 的前一個點記成 $u$。

所有最短路徑演算法，都只是**用不同順序做鬆弛**。

三個性質：
- **三角不等式**：$\delta(s,v)\le\delta(s,u)+w(u,v)$
- **上界性質**：永遠 $v.d\ge\delta(s,v)$；一旦相等就不會再變
- **路徑鬆弛**：最短路徑 $s=v_0,v_1,\dots,v_k$ 的邊**依序**被鬆弛過（中間穿插別的也沒關係），$v_k.d$ 就是正確答案

?? 選擇 | 做了一堆鬆弛之後，$v.d$ 有可能比真正的 $\delta(s,v)$ 小嗎？
[ ] 可能
[x] 不可能
!! 每次更新的值，都對應一條真的走得到的路。
>> 上界性質：$v.d$ 只會從上面逼近。

?? 寫 | 在手寫板：邊 $s\to a$（4）、$s\to b$（1）、$b\to a$（2）、$a\to c$（1）。依序鬆弛 $(s,a)$、$(s,b)$、$(a,c)$、$(b,a)$、$(a,c)$，寫出每一步之後的 $a.d$、$b.d$、$c.d$。
== $(s,a)$：$a=4$；$(s,b)$：$b=1$；$(a,c)$：$c=5$
== $(b,a)$：$a=3$；$(a,c)$：$c=4$

>> 最短路 $s\to b\to a\to c$ 的邊依序被鬆弛過，所以 $c.d=4$ 正確。

**負環**：繞一圈權重總和 $<0$ 的環。如果從 $s$ 走得到它，就可以一直繞、越繞越短 → $\delta=-\infty$，最短路徑沒有定義。

?? 選擇 | 「最短路徑的子路徑也是最短路徑」對嗎？
[x] 對
[ ] 不對
!! 如果中間有一段不是最短，換成更短的會怎樣？
>> 整條會變更短，矛盾。這是最佳子結構，所以能用 DP／貪婪的想法。

@例題 為什麼「最短路徑的邊依序被鬆弛過，$v_k.d$ 就正確」？用歸納說明前兩步。
@寫 起點 | $v_0=s$，$s.d=0=\delta(s,s)$ ✓
@寫 歸納 | 假設鬆弛 $(v_{i-1},v_i)$ 時 $v_{i-1}.d=\delta(s,v_{i-1})$。鬆弛後 $v_i.d\le\delta(s,v_{i-1})+w=\delta(s,v_i)$（因為這段在最短路徑上）
@步 結合上界性質 | 又 $v_i.d\ge\delta(s,v_i)$，所以相等，之後也不會再變
@答 一路推到 $v_k$。

title: Dijkstra 與各種最短路徑演算法的比較
mins: 40

> [!先記住]
> **Dijkstra**：每次從還沒定案的點裡，挑 $d$ 最小的定案，然後鬆弛它的出邊。像水從起點往外漫開。前提是**所有邊權重 $\ge0$**。

```fig
graph
nodes: s*@0,1 a@1,0 b@1,2 c@2,1
edges: s>a:4 s>b:1* b>a:2* a>c:1* b>c:5
cap: 定案順序：s(0) → b(1) → a(3，經 b) → c(4，經 b、a)
```

**Dijkstra**（權重都 $\ge0$）：
1. 所有點放進優先佇列（以 $d$ 為鍵）
2. 每次取出 $d$ **最小**的點 $u$，**鎖住**（答案確定）
3. 鬆弛 $u$ 出去的每條邊
4. 重複直到佇列空

?? 選擇 | Dijkstra 每一步取出哪一個點？

[ ] 離 $s$ 邊數最少的
[ ] 編號最小的

>> 最小的那個不可能再被更短的路更新（後面的路只會更長）。

**時間**（取最小 $V$ 次、減鍵最多 $E$ 次）：
| 優先佇列 | 時間 |
|---|---|

| 情況 | 用 |
|---|---|

title: Bellman-Ford：有負邊的時候
mins: 35
goal: 知道 Dijkstra 遇到負邊為什麼會錯、為什麼不能「每條邊加常數」；會跑 Bellman-Ford、知道它怎麼偵測負環；會把差分約束轉成最短路徑

**全點對最短路徑**，有負邊但沒有負環。從每個點跑一次 Bellman-Ford 要 $O(V^2E)$，太慢。Johnson 的想法：**把權重改成非負**，再從每個點跑 Dijkstra。

不能加常數（上一節）。改用每個點一個「位能」$h(v)$：
$$\hat w(u,v)=w(u,v)+h(u)-h(v)$$

?? 填空 | $w(u,v)=-3$、$h(u)=0$、$h(v)=-5$。$\hat w(u,v)=$？
== 2
!! $-3+0-(-5)$。
>> 變成非負了。

**為什麼最短路徑不變**：一條路徑 $v_0\to v_1\to\cdots\to v_k$ 的新權重
$$\hat w(p)=w(p)+h(v_0)-h(v_k)$$
中間的 $h$ 全部抵消！同起點、同終點的路徑都加**一樣的量**，誰最短不會變。

?? 寫 | 在手寫板展開 $v_0\to v_1\to v_2$ 的新權重，驗證上面的式子。
== $\hat w=[w(v_0,v_1)+h(v_0)-h(v_1)]+[w(v_1,v_2)+h(v_1)-h(v_2)]$
== $=w(v_0,v_1)+w(v_1,v_2)+h(v_0)-h(v_2)$，$h(v_1)$ 抵消
!! 一正一負。
>> 這叫「伸縮相消」。

**怎麼選 $h$ 讓 $\hat w\ge0$**：加一個新點 $q$，連到每個點（權重 0），跑 Bellman-Ford，令 $h(v)=\delta(q,v)$。由三角不等式 $h(v)\le h(u)+w(u,v)$，所以 $\hat w\ge0$。

?? 選擇 | 為什麼 $h(v)=\delta(q,v)$ 會讓 $\hat w(u,v)\ge0$？
[x] 三角不等式：$\delta(q,v)\le\delta(q,u)+w(u,v)$
[ ] 因為 $h$ 都是正的
[ ] 因為 $q$ 沒有入邊
!! 把 $\hat w\ge0$ 移項。
>> $w(u,v)+h(u)-h(v)\ge0$ 就是三角不等式。

步驟與時間：
1. 加 $q$，Bellman-Ford：$O(VE)$（順便偵測負環）
2. 重新加權
3. 每個點跑 Dijkstra：$V\times O(E\lg V)$
4. 換回原本的權重：$\delta(u,v)=\hat\delta(u,v)-h(u)+h(v)$

總共 $O(VE\lg V)$；稀疏圖比 Floyd–Warshall 的 $O(V^3)$ 快。

[x] 稀疏圖（$E$ 遠小於 $V^2$）
[ ] 稠密圖
[ ] 有負環的圖
!! 比較 $VE\lg V$ 和 $V^3$。
>> 有負環兩個都不行。

> **生成樹**：連起所有 $V$ 個點、剛好 $V-1$ 條邊、沒有環。**最小生成樹（MST）**：邊的權重總和最小的那棵。關鍵定理是 **cut property**：任何一刀切開，跨過去最輕的邊一定可以用。


**最小生成樹**（MST）：連通、無向、有權重的圖，挑 $V-1$ 條邊把所有點連起來，總權重最小。

title: P、NP、NP-hard、NP-complete

> [!先記住]

這裡講的都是**判定問題**（答案是「是」或「否」），例如「圖裡有沒有長度 $\le k$ 的路徑？」

- **P**：能在**多項式時間解出來**
- **NP**：給你一個「證據」（例如一條路徑），能在**多項式時間驗證**答案是「是」
- P ⊆ NP（會解就會驗證）。P 是否等於 NP：**還沒有人知道**

=== al-np#4
title: 近似演算法：難題的退而求其次
mins: 30
goal: 知道近似比的意思；會做點覆蓋的 2-近似並證明；知道 metric TSP 的 2-近似、一般 TSP 沒有常數近似；知道 set cover 的貪婪近似
---
> [!先記住]
> NP-hard 的最佳化問題可能沒有快速的精確解，就退一步：找一個**保證不超過最佳解 $\rho$ 倍**的解，叫 **$\rho$-近似**。

```fig
graph
nodes: c*@1,1 1@0,0 2@2,0 3@0,2 4@2,2
edges: c-1* c-2 c-3 c-4
cap: 星形圖：最佳點覆蓋只要 {c}（1 個）。近似法挑 c–1，兩端都選 → {c, 1}，2 個，剛好是 2 倍
```

NPC 問題（大概）沒有多項式時間的**最佳**解。退而求其次：多項式時間、保證**不會差太多**。

**近似比** $\rho$：演算法的答案跟最佳解的比值最多 $\rho$（最小化問題：$C\le\rho C^*$）。

**點覆蓋 2-近似**：
1. 隨便挑一條邊 $(u,v)$，**兩端都選**
2. 刪掉所有碰到 $u$ 或 $v$ 的邊
3. 重複到沒有邊

?? 選擇 | 上面的點覆蓋演算法，近似比是多少？
[x] 2
[ ] 1.5
[ ] $\lg n$
!! 每挑一條邊選了 2 個點，最佳解至少要選幾個？
>> 最多是最佳的 2 倍。

?? 寫 | 在手寫板證明點覆蓋演算法是 2-近似。設挑到的邊集合是 $A$。
== $A$ 裡的邊兩兩不共用端點（挑完就刪掉相鄰的邊）
== 最佳解 $C^*$ 要蓋住 $A$ 的每條邊，一個點只能蓋 $A$ 的一條 ⇒ $|C^*|\ge|A|$；輸出 $2|A|\le2|C^*|$
!! 先找最佳解的下界。
>> 近似證明的套路：找一個最佳解一定 ≥ 的量。

**TSP**：
- **Metric TSP**（距離滿足三角不等式）：做 MST、前序走訪、跳過重複的點 → **2-近似**（Christofides 是 1.5）
- **一般 TSP**：除非 P＝NP，**沒有任何常數**近似比

?? 選擇 | 為什麼 metric TSP 的「MST 前序走訪」最多是最佳的 2 倍？
[x] 最佳路線拿掉一條邊就是生成樹，所以 MST ≤ 最佳；走訪 MST 每條邊走兩次，跳過重複點不會變長
[ ] 因為 MST 很小
[ ] 因為前序走訪是最佳的
!! 「跳過」為什麼不會變長？
>> 三角不等式：直接走過去不會比繞路長。

**Set cover**（用最少的集合蓋住全部元素）：每次挑「蓋住最多還沒被蓋的」→ 近似比 $\le\ln n+1$。

?? 選擇 | 「一般 TSP 有 2-近似演算法」對嗎？
[ ] 對
[x] 不對（除非 P＝NP）
!! 沒有三角不等式，跳過重複點可能變很長。
>> 可以證明：有常數近似就能解漢米頓迴路。
