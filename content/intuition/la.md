=== la-systems
**一句話**　解 $Ax=b$ 就是在問：用 A 的每一行（直的那排）當原料，各放多少，能不能調出 b？

**想像一下**　A 的每一行是一種果汁的成分，b 是你想要的口味，x 是每種果汁各倒幾杯。

```fig
matrix
matrix: 1 2 3 ; 4 5 6
name: A
pivot: 1,1 2,2
free: 3
cap: 2 個方程、3 個未知數：最多 2 個「樞紐」，第 3 個未知數一定是自由的 → 一定有非零解
```

**動手算一次**　$x+2y=5$、$3x+4y=6$：第二式減掉 3 倍的第一式 → $-2y=-9$ → $y=4.5$，$x=-4$。LU 分解就是把「減了幾倍」（3）記在 L 裡，消完的結果是 U。

**rank 是什麼**　消完以後還剩幾個「有用的」橫列。例如 $\begin{bmatrix}1&2&3\\4&5&6\\7&8&9\end{bmatrix}$ 第三列 = 2×第二列 − 第一列，是多餘的 → rank 2。

**小心**
- 有解 ⇔ b 調得出來（在行空間裡）。
- 有一個解時，所有解 = 那個解 + 任何「調出 0 的配方」。
- 方程比未知數少時，$Ax=0$ 一定有非零解；但 $Ax=b$ 可能根本無解。

=== la-vs
**一句話**　向量空間 = 可以「加起來」、「放大縮小」，而且怎麼弄都不會跑出去的一群東西。基底 = 最少的一組積木，裡面每個東西都能用它們唯一地拼出來。

**想像一下**　所有顏色都能用紅、綠、藍各加多少調出來；紅綠藍就是一組基底，所以顏色空間是 3 維。

```fig
plane
range: -1 4 -1 3
vec (1,0) "e₁"
vec (0,1) "e₂"
vec (3,2) hl "(3,2) = 3e₁ + 2e₂"
cap: 平面上任何一點都能用 e₁、e₂ 拼出來，而且拼法只有一種
```

**動手算一次**　次數 ≤ 2 的多項式 $a+bx+cx^2$ 是 3 維空間，基底 $\{1,x,x^2\}$。微分是線性變換：$1\to0$、$x\to1$、$x^2\to2x$。它把 3 維壓成 2 維（$x^2$ 那一項消失），被壓成 0 的是常數（1 維）：$3=1+2$。

**小心**
- 子空間一定要包含 0。
- 兩個子空間「合起來（聯集）」通常不是子空間，「相加」才是。

=== la-det
**一句話**　行列式 = 矩陣把一個「1×1 的正方形」變形以後，面積變成幾倍（翻面就是負的）。面積變 0 就是被壓扁了，回不去（不可逆）。

**想像一下**　擀麵皮：正方形的麵皮被擀成平行四邊形，面積放大幾倍，就是行列式。

```fig
plane
range: -0.5 3.5 -0.5 4.5
poly (0,0) (1,0) (1,1) (0,1) "1"
poly (0,0) (2,1) (3,4) (1,3) hl "5"
cap: 矩陣 [[2,1],[1,3]] 把小正方形（面積 1）拉成平行四邊形，面積 = 2×3 − 1×1 = 5
```

**動手算一次**　$\det\begin{bmatrix}2&1\\1&3\end{bmatrix}=2\cdot3-1\cdot1=5$。$\begin{bmatrix}1&2\\2&4\end{bmatrix}$ 的兩行在同一條線上，壓成一條線，面積 0 → 不可逆。

**為什麼 det(AB) = det(A)·det(B)**　先放大 2 倍再放大 3 倍，總共放大 6 倍。

**小心**
- $\det(A+B)\ne\det A+\det B$。
- $\det(kA)=k^n\det A$（每個方向都放大 k 倍）。
- 三角矩陣的行列式 = 對角線相乘。

=== la-eigen
**一句話**　特徵向量 = 被矩陣作用以後，方向不變、只被拉長或縮短的向量。拉長幾倍就是特徵值。

**想像一下**　揉麵團時，大部分的方向都被扭歪了，但有一兩個方向只是單純被拉長或壓扁。

```fig
plane
range: -2 4 -2 4
vec (3,3) hl "Av = 3v"
vec (1,1)
text (-1.8,1.4) "v = (1,1)"
vec (1,-1) good "w：Aw = w"
vec (1,0) bad
vec (2,1) bad
text (2.1,0.55) bad "A(1,0) = (2,1)"
text (0.35,-0.45) bad "(1,0)"
cap: A = [[2,1],[1,2]]：(1,1) 被拉長 3 倍、(1,−1) 不變；(1,0) 被扭到別的方向，所以不是特徵向量
```

**動手算一次**　$A(1,1)=(3,3)=3(1,1)$ → 特徵值 3；$A(1,-1)=(1,-1)$ → 特徵值 1。驗算：對角線加起來 $2+2=3+1$ ✓；行列式 $4-1=3\times1$ ✓。

**有什麼用**　$A=PDP^{-1}$ 時，$A^{100}=PD^{100}P^{-1}$：只要把 3 和 1 各自做 100 次方。

**小心**
- 不是每個矩陣都能對角化：$\begin{bmatrix}1&1\\0&1\end{bmatrix}$ 只有一個特徵方向。
- 0 是特徵值 ⇔ 有方向被壓成 0 ⇔ 不可逆。

=== la-ortho
**一句話**　投影 = 找 b 在某條線（或某個平面）上的「影子」。影子到 b 的那條線，一定跟地面垂直；最小平方法就是在找這個影子。

**想像一下**　正午太陽照著一根竿子：影子是地面上離竿頂最近的點，竿頂到影子的線垂直地面。

```fig
plane
range: -0.5 3 -1.5 6.5 stretch
line 5 -3 hl
pt (0,6)
pt (1,0)
pt (2,0)
seg (0,6) (0,5) dash bad
seg (1,0) (1,2) dash bad
seg (2,0) (2,-1) dash bad
text (0.12,6.2) "(0,6)"
text (1.1,-0.6) "(1,0)"
text (2.1,0.3) "(2,0)"
text (1.25,3.2) hl "y = 5 − 3t"
cap: 三個點找一條最貼近的直線：誤差（紅色虛線）是 1、−2、1，平方加起來最小
```

**動手算一次**　點 (0,6)、(1,0)、(2,0)，找 $y=C+Dt$。解 $A^TA\hat x=A^Tb$：$\begin{bmatrix}3&3\\3&5\end{bmatrix}\hat x=\begin{bmatrix}6\\0\end{bmatrix}$ → $C=5$、$D=-3$。誤差 $(1,-2,1)$ 跟 $(1,1,1)$、$(0,1,2)$ 都垂直 ✓。

**Gram–Schmidt**　每來一個新向量，就減掉它在前面向量上的影子，剩下的部分就垂直了，再把長度變成 1。

**小心**
- 投影兩次跟投影一次一樣：$P^2=P$。
- 正交矩陣不改變長度，而且 $Q^T=Q^{-1}$。

=== la-sym-svd
**一句話**　對稱矩陣一定可以找到幾個互相垂直的方向，在這些方向上只是單純伸縮。SVD 說：任何矩陣都是「轉一下 → 伸縮 → 再轉一下」。

**想像一下**　對稱矩陣把一個圓壓成橢圓：橢圓的長軸、短軸就是特徵向量，軸有多長就是特徵值。

```fig
plane
range: -3.5 3.5 -3.5 3.5
vec (2.12,2.12) hl "長軸：λ = 3"
vec (0.71,-0.71) good "短軸：λ = 1"
vec (-2.12,-2.12) hl
vec (-0.71,0.71) good
cap: [[2,1],[1,2]] 把圓拉成橢圓：沿 (1,1) 拉長 3 倍、沿 (1,−1) 不變，兩個方向互相垂直
```

**動手算一次**　判斷 $\begin{bmatrix}2&1\\1&2\end{bmatrix}$ 是不是正定：特徵值 3、1 都大於 0 ✓；或左上角的行列式 $2>0$、$3>0$ ✓。對應的二次式 $2x^2+2xy+2y^2=(x+y)^2+x^2+y^2$，只要不是 0 就一定大於 0。

**SVD 的用處**　只保留最大的幾個伸縮倍數（奇異值），就是最好的壓縮——圖片壓縮就是這樣。

**小心**
- 正定要「每一個」左上角行列式都 > 0；半正定只看左上角的不夠。
- 奇異值永遠 ≥ 0；特徵值可以是負的。
