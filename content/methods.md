## 先說結論

一個月讀完六科而且要上台大，靠的不是「讀很多遍」，而是**每天都被迫把東西提取出來、講清楚、找出錯在哪**。這個網站的每個功能都在做這件事。下面是對應關係，照著用就好。

| 學習法 | 證據說它有效的原因 | 在網站裡是哪個功能 |
|---|---|---|
| **費曼學習法** | 講得出完整因果鏈，才代表真的理解；講不出來的那一步就是缺口 | 每章最後的「費曼關卡」，Agent 逐步檢查思考鏈，有跳步就退回並追問 |
| **主動回想**（retrieval practice） | 從記憶中提取比重讀更能鞏固記憶 | 章首的「讀前先回想」；「主動回想模式」把重點遮起來，先講再看 |
| **白紙回憶**（blurting） | 不看書寫出全部記得的內容，最能暴露遺忘 | 每天早上的「晨間白紙回憶」，寄給 Agent 對照漏掉什麼 |
| **間隔重複＋FSRS 記憶模型** | 在快忘記時複習，記憶保留最久；FSRS 為每一題、每一張卡估計「穩定度」，預測你此刻還記得的機率 | 做過的每一題、每張必背卡、每種計算題型，都在記得機率掉到目標保留率（預設 90%）時才再出現；考前自動把間隔壓在考試日之前 |
| **必背卡**（提取＋判斷） | 台大多選題考的是「看起來對但錯」的敘述；快速判斷 ✓／✗ 是最直接的提取練習 | 從教材自動抽出 390 張：149 張陷阱判斷、21 張考點、220 張回想題；只開放已讀或計畫已到的章節 |
| **讀前預測驗**（pretesting） | 先被問過的問題，讀的時候會主動找答案；就算猜錯也比直接讀記得牢 | 還沒讀的章節頂端有「讀前預測驗」：先猜 3 題，只公布正解不給詳解，也不計入錯題 |
| **適度困難**（desirable difficulty） | 太簡單學不到、太難會放棄；研究建議讓答對率維持在八成多 | 「自適應練習」：模型即時估計你每章的掌握度，挑「預測答對率約 82%」的題目，弱章優先、各章交錯 |
| **交錯練習**（interleaving） | 混合不同題型，逼自己先判斷「這是哪一類問題」 | 「混合練習」與「自適應練習」每題先不露章名：讀完題目，先從 4 個章名選「這題要用哪一章的方法」，選完才出現作答區；選錯的會記下來（你把哪章誤認成哪章）。讀過 3 章以上，推薦每天排一次 10 題 |
| **後設認知**（信心度校準） | 知道自己「不知道」比答對更重要；高信心答錯是最頑固的迷思 | 作答前必選信心度（紙筆模式也一樣：寫完先標「猜的／有把握／很確定」才對答案）；「學習儀表板」畫出校準：你說「非常確定」時實際答對幾成；過度自信會出現在督導警報 |
| **高信心答錯優先**（hypercorrection effect） | 很確定卻答錯的題目，訂正後反而最容易記牢——前提是很快再考一次 | 很確定卻答錯的題，到期複習時排在最前面，「快忘的題目」推薦一定會帶到它們 |
| **掌握度追蹤** | 憑感覺判斷「這章會了」通常偏樂觀 | 學習儀表板的章節掌握度熱圖（Elo 模型），≥ 85% 才算台大水準；點任一格就針對那章練 |
| **例題—練習配對**（example–problem pairs） | 看完一題例題，馬上做一題同類型、換了數字的題目，比連看兩題例題或一開始就硬做都學得好 | 每章「例題演練」看完答案後的「換數字，自己做一題」（有隨機題產生器的章，每次數字都不同） |
| **例題逐步淡出**（faded worked examples） | 從看懂到會做，中間要一步一步把提示拿掉，比直接跳到自己做更穩 | 例題做完後「再做一次」：第二次後半步只寫「第 N 步」，要自己想這步做什麼；第三次整題自己寫，寫完才一次翻開全部做法 |
| **手寫作答＋逐行批改** | 考場是手寫；把真的寫出來的過程交給別人逐行看，才抓得到跳步和第一個錯的地方 | 紙筆模式：手寫板寫或「拍紙本」→ 對完答案按「送 Agent 批改這份手寫」，Agent 回覆哪幾行對、第一個錯在哪 |
| **錯誤分析** | 只看正解不會改變錯誤的思路 | 答錯必填錯因（觀念不清／推理跳步／計算失誤／題意誤讀／粗心／沒背熟）與「我原本以為…但其實…」 |
| **雙重編碼**（dual coding） | 文字＋圖像兩條路徑記得更牢 | 每章的「60 秒看懂」短影音；動畫實驗室：先預測下一步，再按「下一步」驗證 |
| **憑記憶畫圖**（drawing to learn） | 看得懂圖不代表畫得出來；自己把圖畫出來，圖才變成你能在考卷上產出的東西 | 練習頁「憑記憶畫圖」：只給段落標題和圖的種類，在手寫板畫出來，再翻開原圖對照自評；畫不出來的下次先出。讀過的章節每天推薦 3 張 |
| **追問為什麼**（elaborative interrogation） | 能說出「為什麼」才算懂；只記結論，換個問法就不會 | 必背卡的對錯卡判斷完，先用一句話講出為什麼對／錯（或舉反例），按「講好了」才看理由；跟理由不一樣就評「忘了／困難」 |
| **刻意練習** | 針對弱點、立即回饋、反覆 | 無限隨機題（答案由模擬器算，永遠不會做完）；台大難度題；Agent 依弱點出題 |
| **番茄鐘＋時數紀錄** | 專注時段＋強制休息，避免假性讀書 | 今日督導的專注計時，只有按下開始的時間才算 |
| **模擬考** | 在考試條件下提取，訓練時間分配與抗壓 | 三科全真模考，100 分鐘、交卷前不給回饋。預設是**紙筆考**：整份題目給你、不標章節，在紙上寫完，交卷後逐題對答案自評（練習頁「模考」旁邊可以切回點選） |
| **考後反思單**（exam wrapper） | 考完只看分數不會進步；把失分歸因、寫成下次的具體行動才會 | 模考交卷後填反思單：失分原因、最花時間的題、下次要改變的一件事（寫成「如果……就……」），之後每天的今日督導都會提醒你 |
| **外部監督** | 有人看著，執行率會大幅提高 | 每日任務、打卡、連續達標天數、督導警報，以及 Agent 每天的督導訊息 |
| **降低起步成本**（5 分鐘法則） | 拖延最難的是開始；只承諾 5 分鐘，開始後通常會繼續 | 「帶我讀」只給一件事、一個按鈕；「只做 5 分鐘」；按開始自動啟動專注計時；離開回來直接給下一步 |
| **環境提示**（cue） | 固定時間、固定觸發，比靠意志力可靠 | `setup_autostart.bat` 讓電腦每天定時＋開機自動打開網站；到點、快到打卡時間會跳通知 |
| **承諾與損失規避** | 說出口的承諾、自己定的代價、怕失去連續紀錄，都會提高執行率 | 每天選打卡時間並倒數；「沒打卡的代價」；連續天數「今天沒打卡就歸零」 |
| **絕不連斷兩天** | 斷一天沒關係，連斷兩天習慣就會崩 | 斷掉的隔天跳紅色警告；「保底模式」15 分鐘也能保住連續天數 |
| **誠實的時數** | 假性讀書會讓你高估自己 | 切到別的分頁不計時；8 分鐘沒動作自動暫停並詢問 |

## 每天怎麼用（建議流程）

**不想自己排？打開「▶ 帶我讀」，照它給的那一步做就好。** 下面的流程它已經幫你排進去了，還會依你的記憶狀態與弱點微調。

1. **早上 30 分鐘**：今日督導 → 晨間白紙回憶（寫昨天兩章）→ 必背卡清掉到期卡（通常 10～15 分鐘）。
2. **上午**：第一章。讀前預測驗（3 題）→ 刷「60 秒看懂」→ 讀內容與動畫 → 開「主動回想模式」再過一次 → 交費曼關卡。
3. **下午**：第二章，同樣流程。
4. **晚上**：自適應練習 15 題＋本章練習（湊滿當日題數）→ 錯題寫錯因 → 清空到期複習題 → 晚間打卡寫反省。
5. **每週一次**：看學習儀表板。校準偏了就放慢作答、寫思考鏈；掌握度紅色的章節排進隔天。
5. **Agent**：讓它在背景監聽；費曼被退回的，隔天早上先補。

## 費曼關卡的通過標準（Agent 也照這個審）

1. 涵蓋所有關鍵點（送出後可以對照）。
2. 每一步都有「因為…所以…」，沒有「很明顯」「所以就」帶過的地方。
3. 至少一個具體的例子或數字代入。
4. 說得出結論**什麼時候不成立**（反例、邊界條件、需要的假設）。
5. 沒有觀念錯誤。

少一項就退回。退回不是失敗：退回的那一步，正是考場上會失分的地方。

## 一個月的現實

六科在 30 天內讀到台大程度，每天需要 6 小時以上的有效專注，而且不能有空白日。計畫第 8、16、24 天是複習日，用來補進度與重交費曼。如果某天沒達標，系統會在隔天的督導警報提醒你，Agent 也會在督導訊息中調整後續任務。任何教材都無法保證錄取；能保證的是，照這套流程走完，你會清楚知道自己每一科哪裡還不會。
