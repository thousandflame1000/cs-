# 教材頁的設計筆記（給之後改版面的人）

對象：完全沒底子、很懶的考生，用手機或電腦讀。
這一頁只有一個工作：讓人一段一段讀下去，不迷路、不被一整面字嚇跑。

## 色彩（沿用全站，不另起爐灶）

| 名稱 | 值 | 用途 |
|---|---|---|
| 紙 | `--bg` #eef1f5 | 底 |
| 卡 | `--surface` #ffffff | 內容區 |
| 墨 | `--ink` #18202c | 內文 |
| 淡墨 | `--ink-2` #4b5667 | 說明 |
| 藍 | `--accent` #2f4fd8 | 現在要做的事 |
| 綠 | `--good` #1d8a4a | 做完了 |

科目色 `--sc` 只用在章節標題和路線上的細節，不拿來鋪大面積。

## 字

- 內文：Noto Sans TC，17px，行高 1.85（中文需要比英文高的行距）。
- 章名：Noto Serif TC，當作這一頁的招牌。
- 標題前面用一個 emoji 當圖示：一看就知道這塊是「直覺／跟著做／短片／費曼」，不用讀字。

## 版面

```
[科目｜第幾章]
章名（大、襯線）
[🎬 短片 ✓] → [💡 直覺] → [✏️ 跟著做 2/4] → [📖 分段讀 3/5] → [🧠 費曼]    ← 本章路線，唯一的視覺重點
┌ 💡 先懂直覺 ┐
┌ ✏️ 跟著做一題 ┐
┌ 🎬 60 秒看懂 ┐
┌ 📖 1/5 二元堆積 ┐（一次只展開一段）
┌ 🧠 費曼關卡 ┐
```

- 整欄最寬 780px：每張卡同寬、左邊對齊；內文一行不超過約 40 個中文字。
- 卡片一律白底細框，不再用彩色左邊條；靠標題前的圖示來區分。
- 段落標題前面已經有「1/5」，所以把 Markdown 裡的「1.」拿掉，不重複編號。

## 原則

- 大膽只用在一個地方：「本章路線」。它是真的有順序的流程，所以用箭頭串起來；做完打勾變綠，現在該做的那格是藍色。
- 其他地方安靜：不加陰影、不加漸層、不加進場動畫。
- 手機上路線可以換行，卡片內距縮小，圖片不超出畫面。
