## 2. 發布文案

### YouTube Shorts
**說明**
記憶宮殿 · 計組館第 3 間。執行時間 = 能加速的 + 不能加速的。80% 能加速、壓扁 100 倍，總時間從 10 變 2.08，只快 4.8 倍；壓到 0 也只剩 2，上限 5 倍 = 1 ÷ 0.2。90% 能平行、開 1000 核，加速 9.9 倍，還是不到 10。Gustafson 換了一個假設：時間固定、題目跟著核數變大，10 核快 9.1 倍、100 核快 90.1 倍，接近線性。

**標籤**：#計算機組織 #Amdahl定律 #Gustafson #平行運算 #效能 #資工所 #研究所考試 #記憶宮殿

**置頂留言建議**：強擴展（題目大小固定）看 Amdahl；弱擴展（每核工作量固定）看 Gustafson。

### TikTok / IG Reels
**文案**：把 80% 加速 100 倍，整體只快 4.8 倍。瓶頸永遠是不能加速的那段。存起來考前看。

## 4. 事實核對
- [x] f = 0.8、s = 100：(1 − 0.8) + 0.8/100 = 0.208 → 加速 4.81；原時間 10 → 2.08
- [x] s → ∞：上限 1/(1 − f) = 5
- [x] f = 0.9：N = 10 → 5.26、N = 100 → 9.17、N = 1000 → 9.91；上限 10
- [x] Gustafson（平行部分占 90%）：S = N − 0.1(N − 1)；N = 10 → 9.1、N = 100 → 90.1
