## 2. 發布文案

### YouTube Shorts
**說明**
把遞迴樹的每個子問題畫成一條光，長度就是它的成本：合併排序每層都是 n，疊成長方形，所以 n lg n；改成 4T(n/2)+n，每層翻倍，成本全在 n² 片葉子；改成 2T(n/2)+n²，每層減半，根一層就佔一半以上。三種 case 其實只在比一個倍率 a / bᵈ。最後給考試直接能寫的三行結論。你第一次學 Master 定理是怎麼記的？

**標籤**：#演算法 #MasterTheorem #遞迴式 #時間複雜度 #資工所 #研究所考試 #CLRS #分治法

**置頂留言建議**：f(n)=Θ(nᵈ) 時：a＞bᵈ → Θ(n^(log_b a))；a＝bᵈ → Θ(nᵈ lg n)；a＜bᵈ → Θ(nᵈ)。一般形式見 CLRS 第 4 章。

## 4. 事實核對
- [x] 2T(n/2)+n：每層 n、lg n 層 → Θ(n lg n)
- [x] 4T(n/2)+n：第 j 層 2ʲn，葉子 4^(lg n)=n² 片 → Θ(n²)
- [x] 2T(n/2)+n²：第 j 層 n²/2ʲ，根佔總和 2n² 的一半以上 → Θ(n²)
- [x] 每層倍率 a/bᵈ：第 j 層成本 aʲ(n/bʲ)ᵈ = nᵈ(a/bᵈ)ʲ
