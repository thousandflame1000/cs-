## 2. 發布文案

### YouTube Shorts
**說明**
記憶宮殿 · 演算法館第 2 間。四個點擺進 3D 房間，距離＝柱子高度。Dijkstra 每次挑最近的點並鎖住，前提是後面的路只會更長；但 b → a 是 −2，a 其實只要 1，可是 a 已經鎖住，c 不會再更新，最後 c = 3。真正的最短路 s→b→a→c 是一條先爬到 3、再往下掉的山路，答案是 2。把每條邊都加 2 也沒用：s→a→c 變 7、s→b→a→c 變 8，最短路換人了。有負邊就用 Bellman-Ford。

**標籤**：#演算法 #Dijkstra #最短路徑 #BellmanFord #負邊 #資工所 #研究所考試 #CLRS #記憶宮殿

**置頂留言建議**：Dijkstra 的正確性靠「取出就定案」，需要所有邊權 ≥ 0；Johnson 用頂點位能 ŵ(u,v) = w(u,v) + h(u) − h(v) 才能安全地把負邊變非負。

## 4. 事實核對
- [x] s→a 2、s→b 3、b→a −2、a→c 1；Dijkstra 依序取出 s(0)、a(2)、b(3)、c(3)，c.d = 3
- [x] δ(s,c) = 3 − 2 + 1 = 2（s→b→a→c）
- [x] 每邊 +2：s→a→c = 4+3 = 7，s→b→a→c = 5+0+3 = 8，最短路變成 s→a→c
- [x] Bellman-Ford（順序 sa、sb、ac、ba）：第 1 輪 a=1、b=3、c=3；第 2 輪 c=2；第 3 輪無變化；第 4 輪無更新 → 無負環
