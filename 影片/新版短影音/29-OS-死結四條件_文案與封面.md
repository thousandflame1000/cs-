## 4. 事實核對
- [x] 四個必要條件：互斥、持有並等待、不可搶占、循環等待（Coffman 1971）
- [x] RAG 邊方向：配置邊 R → P、請求邊 P → R；圈 P1 → R2 → P2 → R1 → P1
- [x] 資源全序 F，只能申請 F 更大的資源：若有環則 F(R₀) < F(R₁) < … < F(R₀)，矛盾 → 破循環等待
- [x] 安全狀態 ⇒ 不會死結；不安全不一定死結
