## 2. 發布文案

### YouTube Shorts
**說明**
記憶宮殿 · 線代館第 4 間。座標就是「用這組基底走幾步」。標準基底下 p = (3, 1)；換成 b₁ = (1, 1)、b₂ = (1, −1)，走 2 步 b₁、1 步 b₂ 也到 p，所以新座標是 (2, 1)。P 的欄是新基底：位置 = P × 步數，步數 = P⁻¹ × 位置。b₂ 若跟 b₁ 平行，只走得到一條線——基底要線性獨立、張滿空間。3D 需要 3 根，少一根只剩平面，多一根是多餘的：維度 = 基底個數。

**標籤**：#線性代數 #基底 #座標 #換基底 #維度 #資工所 #研究所考試 #記憶宮殿

**置頂留言建議**：換基底矩陣 P 的欄＝新基底用舊座標寫出來；[x]_new = P⁻¹ x。

## 4. 事實核對
- [x] 2·(1, 1) + 1·(1, −1) = (3, 1)
- [x] P = [[1, 1], [1, −1]]，P·(2, 1) = (3, 1)；P⁻¹ = ½[[1, 1], [1, −1]]，P⁻¹·(3, 1) = (2, 1)
- [x] 平行的兩向量只張出一條直線；R³ 的基底恰好 3 個向量
