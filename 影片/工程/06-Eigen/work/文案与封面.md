## 2. 發布文案

### YouTube Shorts
**說明**
把一整圈箭頭交給矩陣 A = [2 1; 1 2]：大部分箭頭都被轉了方向，只有沿 (1, 1) 的那支被拉長成 3 倍、沿 (1, −1) 的那支長度不變。這就是 Av = λv：v 是特徵向量、λ 是特徵值。計算方法：det(A − λI) = (2 − λ)² − 1 = 0，得 λ = 3、1；最後整圈箭頭被拉成橢圓，半軸正好是 3 和 1。

**標籤**：#線性代數 #特徵值 #特徵向量 #eigenvalue #資工所 #研究所考試 #Strang

**置頂留言建議**：驗算口訣：λ₁ + λ₂ = trace(A) = 4，λ₁λ₂ = det(A) = 3。

### TikTok / IG Reels
**文案**：特徵向量＝被矩陣作用後方向不變的向量。A = [2 1; 1 2] 只有 (1,1) 和 (1,−1) 不轉。存起來考前看。
**話題**：#資工所 #線性代數 #研究所 #讀書

### 來源與聲明
- 出處：Strang《Introduction to Linear Algebra》第 6 章；本站教材 la-eigen
- 示意：「圓被拉成橢圓、半軸＝特徵值」只對對稱正定矩陣成立（本例 A 對稱、特徵值 3、1 皆正）；一般矩陣的橢圓半軸是奇異值

## 4. 事實核對
- [x] A(1,1) = (3,3)，λ = 3；A(1,−1) = (1,−1)，λ = 1
- [x] det(A − λI) = (2 − λ)² − 1；trace 4 = 3 + 1；det 3 = 3 × 1
- [x] 單位圓的像：A 對稱，半軸方向＝特徵向量、長度＝|λ| = 3、1
