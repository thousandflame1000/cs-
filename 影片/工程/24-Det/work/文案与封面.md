## 2. 發布文案

### YouTube Shorts
**說明**
記憶宮殿 · 線代館第 5 間。單位正方形面積 1，乘上 A = [[3, 1], [1, 2]] 變成平行四邊形，面積變 5，det A = 5——而且每一格都放大 5 倍。det 小於 0：面積照算，但翻面了；det = 0：整個壓成一條線，回不去，所以沒有反矩陣。3D 裡是單位立方體變斜方體，體積倍率就是 det。先放大 2 倍再放大 3 倍，總共 6 倍：det(AB) = det A · det B。

**標籤**：#線性代數 #行列式 #determinant #線性變換 #資工所 #研究所考試 #記憶宮殿

**置頂留言建議**：det(A⁻¹) = 1 / det A；det(Aᵀ) = det A；換兩列，det 變號。

## 4. 事實核對
- [x] det [[3, 1], [1, 2]] = 6 − 1 = 5；det [[1, 2], [3, 1]] = −5；det [[1, .5], [2, 1]] = 0
- [x] det [[2, 1, 0], [0, 1, 0], [0, .5, 1.5]] = 2 · (1 · 1.5) = 3
- [x] [[1, 1], [0, 3]] · diag(2, 1) = [[2, 1], [0, 3]]，det = 6 = 3 × 2
