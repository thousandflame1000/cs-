# 16 · 消去法與解的結構（3D）

- 記憶宮殿：線代館 · 第 3 間
- 三個方程式＝三片半透明平面（青、琥珀、粉）。列運算時平面係數內插，那片平面繞著交點 (1, 2, 3) 轉、交點不動
- 第二系統：三片交成白色直線，z 自由變數（琥珀點沿線滑動），零空間＝過原點的平行青線，特解箭頭
- 第三系統：0 = 1 後換回原三片平面，鏡頭轉到交線方向 (1, −2, 1)，三片平面圍成三角形、三條平行交線變三個紅點
- 結尾三件展品直排（點 / 線 / 三稜柱）＋ 秩的判斷，接考試卡
