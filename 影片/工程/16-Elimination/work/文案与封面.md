## 2. 發布文案

### YouTube Shorts
**說明**
記憶宮殿 · 線代館第 3 間。三個方程式 = 三片平面，解就是交點。x + y + z = 6、x + 2y + 3z = 14、x + 4y + 9z = 36：每做一次列運算，其中一片平面繞著交點轉，交點 (1, 2, 3) 不動，方程式越來越簡單，消到上三角往回代。把第三式換成 2x + 3y + 4z = 20，消去後出現 0 = 0：三片平面交成一條線，z 是自由變數，解 = 特解 + 零空間 t(1, −2, 1)。再把 20 改成 21，出現 0 = 1：三片平面兩兩相交成三條平行線，沒有共同點。秩決定一切。

**標籤**：#線性代數 #高斯消去法 #列運算 #秩 #零空間 #Ax等於b #資工所 #研究所考試 #記憶宮殿

**置頂留言建議**：判斷口訣：r(A) = r[A|b] = n 唯一；r(A) = r[A|b] < n 有 n − r 個自由變數；r(A) < r[A|b] 無解。

### TikTok / IG Reels
**文案**：消去法就是讓平面繞著交點轉。出現 0 = 0 是無限多解，出現 0 = 1 是無解。存起來考前看。
