# 27 · 遞迴與特徵方程式（3D）

- 記憶宮殿：離散館 · 第 6 間
- aₙ = aₙ₋₁ + 2aₙ₋₂、a₀ = a₁ = 3：紫色塔 3、3、9、15、33、63；新塔出現時前兩根亮一下
- 猜 rⁿ（琥珀虛線）→ 牆上拋物線 r² − r − 2 碰到 0 在 −1、2
- 拆塔：後排 2·2ⁿ（青）、前排 (−1)ⁿ（粉，一上一下），加起來＝中排 aₙ；α = 2、β = 1
- 重根：r² − 4r + 4 只碰 0 一次 → (α + βn)·2ⁿ；最後比值 aₙ₊₁/aₙ → 2
