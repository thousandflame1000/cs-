## 2. 發布文案

### YouTube Shorts
**說明**
記憶宮殿 · 作業系統館第 3 間。fork() 把整個行程複製一份：父行程拿到子的 PID，子行程拿到 0，兩個都從 fork 的下一行繼續跑。迴圈 fork 三次，每輪所有行程都分裂：1 → 2 → 4 → 8，剛好站在立方體的 8 個頂點（頂點座標＝哪幾次 fork 拿到 0）。printf 放在迴圈裡，印 2 + 4 + 8 = 14 次。fork() && fork() ∣∣ fork()：原行程兩個都是真，∣∣ 短路；兩個子行程各自跑第三個 fork，總共 5 個行程。最後：變數各一份，靠 copy-on-write 寫入才真的複製實體頁。

**標籤**：#作業系統 #OS #fork #行程 #processes #copyonwrite #資工所 #研究所考試 #記憶宮殿

**置頂留言建議**：再想一題：if (fork() == 0) fork(); printf("x"); 印幾次？（答案 3）

### TikTok / IG Reels
**文案**：fork 一次變兩個，三次變八個，排成立方體。&& 和 ∣∣ 會短路，所以是 5 不是 8。存起來考前看。

## 4. 事實核對
- [x] fork 回傳：父得子 PID（> 0），子得 0，失敗 −1
- [x] for (i = 0; i < 3; i++) fork(); → 2³ = 8 個行程
- [x] 迴圈內 printf：第 i 輪有 2^i 個行程各印一次 → 2 + 4 + 8 = 14（= 2⁴ − 2）
- [x] fork() && fork() ∣∣ fork()：原行程 #1 真 #2 真 → || 短路；#1 的子得 0 → && 短路 → 跑 #3（+1）；#2 的子 → && 為假 → 跑 #3（+1）；1 + 1 + 1 + 2 = 5
- [x] fork 後變數各自一份，虛擬位址相同；COW 寫入時才複製實體頁
