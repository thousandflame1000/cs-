## 2. 發布文案

### YouTube Shorts
**說明**
記憶宮殿 · 計組館第 6 間。DIV F0 / ADD F6 / SUB F8 / MUL F6 四條指令：ADD 要 DIV 算出的 F0，MUL 要 SUB 的 F8，這是真相依（RAW），一定要等。ADD 讀 F8、SUB 寫 F8（WAR），ADD、MUL 都寫 F6（WAW），只是名字撞到。換名：每次寫入都給一個新的實體暫存器，名稱相依全部消失，DIV 還在算時 SUB、MUL 就能先做。Tomasulo 用保留站和 CDB 在硬體裡自動做這件事。

**標籤**：#計算機組織 #暫存器換名 #Tomasulo #指令平行 #資工所 #研究所考試 #記憶宮殿

**置頂留言建議**：Scoreboard 沒有換名，WAW 在 issue 擋、WAR 在寫回擋；Tomasulo 在 issue 時把值或標籤抄進保留站，所以兩種都消失。

## 4. 事實核對
- [x] RAW：DIV→ADD（F0）、SUB→MUL（F8）
- [x] WAR：ADD 讀 F8 → SUB 寫 F8；WAW：ADD、MUL 寫 F6
- [x] 換名後 ADD 讀舊 F8 的值不受 SUB 影響；F6 最後的值是 MUL（P4）
