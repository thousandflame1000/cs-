# 22 · IEEE 754 浮點數（3D）

- 記憶宮殿：計組館 · 第 4 間
- 位元牆：第 1 排 9 格＝符號（珊瑚）＋指數 8（琥珀），下面三排＝尾數 23（青）；1 的格子往前凸、發亮
- −6.25：6.25 = 4 + 2 + 0.25 = 110.01 → 1.1001 × 2² → 符號 1、指數 2 + 127 = 129 = 10000001、尾數 1001…（0xC0C80000）
- 數線：3 位尾數的小浮點，1–2 間距 1/8、2–4 為 1/4、4–8 為 1/2；放大 [1/16, 1/8)，0.1 夾在 0.09375 與 0.1015625 之間
- 特殊值：指數全 0 → 0／次正規；全 1、尾數 0 → ∞；尾數不為 0 → NaN

## 修改紀錄
- 靜幀 r1：位元牆與數線左右出畫 → 格子縮小、鏡頭後退；算式壓到「指數 8」標籤 → 算式上移
