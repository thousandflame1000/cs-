## 2. 發布文案

### YouTube Shorts
**說明**
記憶宮殿 · 演算法館第 3 間。12 × 34 拆成十位和個位，面積切成四塊 ac、ad、bc、bd，直接算要乘 4 次。但中間兩塊只需要它們的和：先乘兩個角 ac、bd，再乘一次 (a+b)(c+d) 得到整塊，整塊減兩角就是 ad + bc。每一層只分 3 支，T(n) = 3T(n/2) + O(n)，所以是 Θ(n^lg3) ≈ n 的 1.585 次方。

**標籤**：#演算法 #分治法 #Karatsuba #大數乘法 #資工所 #研究所考試 #記憶宮殿

**置頂留言建議**：Strassen 對矩陣做同樣的事：8 次子矩陣乘法省成 7 次，Θ(n^lg7) ≈ n 的 2.81 次方。

## 4. 事實核對
- [x] ac = 3、ad = 4、bc = 6、bd = 8；(1+2)(3+4) = 21 = 3 + 4 + 6 + 8
- [x] 21 − 3 − 8 = 10 = ad + bc；3·100 + 10·10 + 8 = 408 = 12 × 34
- [x] 3¹⁰ = 59,049、4¹⁰ = 1,048,576；lg 3 ≈ 1.585
