# 31 · BFS 與 DFS（3D）

- 記憶宮殿：資結館 · 第 8 間
- 圖平鋪在地板上：s、a、b、c、d、e，邊 s-a s-b a-b a-c b-d c-e d-e
- 01 BFS：s 放出水波，一層層點亮（BFS 樹邊變青）；每個點升到距離那麼高（梯田 0/1/2/3）；佇列平躺在圖後面，出隊從左、入隊從右：s → a b → b c → c d → d e → e
- 02 DFS：s → a → b → d → e → c 一路到底，走過的點疊成直立的堆疊塔，再一層層退回；標上 進來/離開 時間 1/12、2/11、3/10、4/9、5/8、6/7（括號：包住或分開）
- 03 有向圖 s → a → b → c → a：c → a 打到塔裡的 a＝後向邊＝有環；改成 a → c 後無環，排成 s a b c（拓撲排序）
- 考試卡 4 行：BFS：佇列，求無權最短路／DFS：堆疊，一路走到底／後向邊 ⇔ 有向圖有環／兩者都是 O(V + E)
