## 2. 發布文案

### YouTube Shorts
**說明**
記憶宮殿 · 線代館第 6 間。對稱矩陣 [[2, 1], [1, 2]] 作用在單位圓上，大部分向量會轉向，只有 (1, 1) 和 (1, −1) 兩個方向不轉，它們互相垂直，λ = 3、λ = 1。所以 A = QΛQᵀ：轉、拉、轉回來。特徵值都是正的，xᵀAx 是一個碗（正定）；有一個負的就變成馬鞍。不對稱的矩陣也能拆：A = UΣVᵀ，轉、拉、再轉，σ 就是橢圓半軸的長度。

**標籤**：#線性代數 #對稱矩陣 #譜定理 #正定 #SVD #資工所 #研究所考試 #記憶宮殿

**置頂留言建議**：證明垂直：xᵀAy 算兩次得 (λ − μ)xᵀy = 0，λ ≠ μ 就有 xᵀy = 0。

## 4. 事實核對
- [x] [[2, 1], [1, 2]]：λ = 3（(1, 1)）、λ = 1（(1, −1)）
- [x] [[1, 2], [2, 1]]：λ = 3、−1 → 不定（馬鞍）
- [x] [[1, 1], [0, 1]]：AᵀA = [[1, 1], [1, 2]]，特徵值 (3 ± √5)/2 → σ = 1.618、0.618
