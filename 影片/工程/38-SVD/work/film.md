# 38 · 對稱矩陣與 SVD（3D）

- 記憶宮殿：線代館 · 第 6 間
- 01 不轉的方向：單位圓平鋪在地板，八根箭頭；A = [[2, 1], [1, 2]] 慢慢作用 → 圓變橢圓，大部分箭頭轉向，只有 ±(1, 1)（綠，λ = 3）和 ±(1, −1)（琥珀，λ = 1）方向不變；直角記號「互相垂直」
- 02 碗與馬鞍：QΛQᵀ 分三段（Qᵀ 轉 −45°、Λ 沿軸拉 3 與 1、Q 轉回來）；xᵀAx 從地板升成綠色的碗（λ = 3、1 都 > 0，正定）→ 換成 [[1, 2], [2, 1]]，曲面變成馬鞍，負的部分珊瑚色（λ = 3、−1，不定）
- 03 SVD：剪切 [[1, 1], [0, 1]] 把紫色圓壓斜 → 重播成 Vᵀ 轉、Σ 拉、U 轉；半軸 σ₁ ≈ 1.618（綠）、σ₂ ≈ 0.618（琥珀），σ² = AᵀA 的特徵值
- 考試卡 4 行：實對稱：λ 是實數、向量垂直／A = QΛQᵀ／正定 ⇔ λ 全 > 0 ⇔ 碗／SVD：A = UΣVᵀ，σ = 半軸
