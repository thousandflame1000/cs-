# 43 · 雇用問題（3D）

- 記憶宮殿：演算法館 · 第 8 間
- 十個應徵者排成一排柱子，高度＝能力（3 7 2 5 9 1 6 10 4 8）；琥珀色「目前最好」橫桿往右掃，比它高就換人（柱子變綠）
- 01 換人：隨機順序換 4 次；排成 1…10 遞增換 10 次（最壞 n 次）；「隨機順序，平均換幾次？」
- 02 機率 1/i：前 5 根聚焦，綠色「最好」光點在 5 個位置之間跳 → P = 1/5、一般 1/i；每根柱子底下一顆 0/1 指示方塊：1 + 1 + 0 + 0 + 1 + 0 + 0 + 1 + 0 + 0 = 4
- 03 期望值：柱子變成 1/i 的高度（琥珀），E[X] = Σ E[Xᵢ] = Σ 1/i（期望值線性，不用獨立）；綠色 1/x 曲線 → Hₙ ≈ ln n、H₁₀ ≈ 2.93；n = 100 → 5.19 次，最壞 100 次
- 考試卡 4 行：Xᵢ = I{ 第 i 人被雇 }／P(Xᵢ = 1) = 1/i（隨機順序）／E[X] = Σ 1/i = Hₙ／Hₙ = ln n + O(1)
