# 資工所衝刺站

台大資工所考科（數學：線代＋離散／計算機結構與作業系統／資料結構與演算法）的 30 天衝刺系統：六科 42 章教材、145 題題庫（含詳解與證明題參考解答）、37 種無限隨機計算題、21 個可逐步播放的動畫實驗室、43 支有配樂音效的直式短影音（42 章每章都有）、390 張自動生成的必背卡（FSRS 記憶模型排程）、自適應練習、學習儀表板（遺忘曲線／信心校準／章節掌握度）、讀前預測驗、模考反思單、每日監督，以及用「檔案」和 AI Agent 互動的費曼關卡。

## 開始使用

1. 雙擊 **`start.bat`**。需要 Python 3（沒有的話到 python.org 安裝，安裝時勾選「Add python.exe to PATH」）。瀏覽器會自動打開 `http://127.0.0.1:8765`。黑色視窗不要關，關掉網站就斷線。
2. 到「設定」填名字、**考試日**（預設 2027-02-06，請依台大招生簡章修改）與 30 天計畫的起始日。
3. **每天打開網站就是「帶我讀」頁：它只顯示「現在做這一件事」，按「開始」就好**。順序由系統依 30 天計畫、記憶狀態（FSRS）和弱點自動排好；做完會自動換下一件，在其他頁面時左下角的「下一步」按鈕會帶你回來。第一次打開會先問 3 個問題（考試日、每天幾小時、從哪天開始）。

## 線上版（最省事：手機、任何電腦都能用）

線上版網址：https://claude.ai/artifact/X7U9kctdmvNFoCqbrRMsPC（要登入你的 Claude 帳號）

- **進度存在雲端**：手機、家裡電腦、學校電腦打開同一個連結，看到的是同一份進度。
- **Claude 直接在網頁裡當家教**：交費曼、按「問 Agent」、🆘 完全不會、晚上打卡、請它出題，Claude 都會馬上回答或批改，不用開電腦、不用等排程。第一次會跳出「允許這個頁面使用 Claude」，按允許（會用到你的 Claude 額度）。
- **💬 用聊天過費曼關卡**：不想寫 200 字長文，就按這個；Claude 一次只問一個小問題，你回一兩句就好，全部講對就通過。
- 想把電腦版的進度併過來：電腦版「設定 → 下載備份檔」，線上版「設定 → 合併另一台的進度檔」。

## 裝成 App、手機一起用

- **電腦**：用 start.bat 打開後，到「設定 → App 與手機」按「安裝到桌面」（或網址列右側的安裝圖示）。之後從桌面圖示打開；就算黑色視窗沒開也能讀、能做題，開了之後進度自動補同步。
- **手機**：同一頁按「打開手機連線」，手機連同一個 Wi-Fi 掃 QR code 打開，再選「加到主畫面」。手機和電腦輪流用，進度會自動合併；只有掃過碼的手機能讀寫你的進度，按「關閉手機連線」就立刻斷開。第一次會跳出 Windows 防火牆詢問，請按「允許」。
- **每天早上的推播**：Claude 的排程任務會在早上讀你的進度，把「今天第一步」推到手機上的 Claude App；晚上沒做完會再提醒一次（電腦要開著、Claude 桌面版要開著）。

沒有 Python：用 Chrome 或 Edge 直接打開 `web/index.html`，到「Agent 對話」按「連接 bridge 資料夾」選 `bridge`，效果一樣（每次開瀏覽器可能要重新授權一次）。

## 對抗惰性（懶的時候它會推你一把）

- **電腦自動把網站打開**：雙擊 `setup_autostart.bat`，輸入每天開始讀書的時間（例如 08:30）和晚上打卡時間。之後每天到點、以及開機登入時，網站會自己打開到「帶我讀」。不想要了就執行 `remove_autostart.bat`。
- **只做 5 分鐘**：提不起勁時按這個，系統挑一件 5 分鐘就能做完的事（通常是到期必背卡）。開始了通常就會繼續。
- **保底模式**：很累的日子按「今天很累」，只剩 10 題＋到期卡＋打卡（約 15 分鐘），連續天數不會斷。規則只有一條：**絕不連斷兩天**。
- **承諾與代價**：每天選一個打卡時間；第一次使用時可以寫「沒打卡的話我願意……」。斷掉的隔天，網站和 Agent 都會把你自己寫的這句話拿出來。
- **提醒**：開啟「🔔 提醒」後，到了讀書時間還沒開始、快到打卡時間、或專注計時中切出去太久，都會跳通知（網站要開著，放在背景也行）。
- **發呆偵測**：專注計時中 8 分鐘沒任何動作，計時會暫停並問你「還在嗎？」，那段時間不算讀書時數。
- **回來就給下一步**：離開 15 分鐘以上再回來，直接跳出「下一步：……［開始］」，不用重新想要做什麼。
- **進度預測**：「照目前速度，考前讀得完幾章」會一直顯示在帶我讀頁面上。

## 短影音（60 秒看懂）

- 網站左邊點「短影音」：上下滑連續刷，滑到哪支就從頭播。鍵盤 ↓/↑ 換片、空白鍵暫停、M 開關聲音。
- 有對應短片的章節，最上面會有「60 秒看懂」；今日督導頁也會提醒「開讀前先刷」。
- 配樂與音效由瀏覽器即時合成（不用網路）。瀏覽器規定要先點一下頁面才會出聲；右上角 🔊 可靜音，會記住。
- 手機版：`影片/短影音/` 有 43 支直式 MP4（檔名依科目編號），`影片/短影音合輯（直式）1～3.mp4` 是全部串在一起的版本（每段約 6～7 分鐘）。

## 叫 Agent 監聽（土法：檔案就是通道）

網站把你的提問、費曼解釋、打卡寫進 `bridge/inbox.jsonl`；Agent 讀它、把回覆寫進 `bridge/outbox.jsonl`；網站每 3 秒讀一次。網站左上角顯示「Agent 監聽中」就代表有 Agent 在看。

- **Claude Code／Codex**：在這個資料夾開啟它，說「監聽」。它會照 `AGENTS.md` 反覆執行 `python agent.py watch`。
- **Claude App（電腦已連到 Claude 桌面版時）**：直接跟 Claude 說「監聽我的資工所衝刺資料夾」，它會讀 inbox、寫 outbox。
- **最土的方式**：自己打開 `bridge/outbox.jsonl` 在最後加一行字並存檔，網站就會顯示。

**多個 Claude 帳號都能用**：每個帳號開一個 Claude Code（或 Codex）在這個資料夾，用 `--name` 與 `--only` 分工，例如一個帳號只審費曼關卡與申論（`python agent.py watch --name A --only feynman,essay,blurt`），另一個負責回答問題與打卡督導（`--name B --only ask,checkin,request`）。工具會擋掉重複回覆。

`AGENTS.md` 寫了 Agent 的完整規則：費曼關卡怎麼審（五個標準、退回時只追問不給答案）、怎麼出題、怎麼做每日督導。

## 每日監督

- **網站內建**：每日任務（白紙回憶、兩章精讀、兩個費曼關卡、題數、錯題、專注時數）、打卡、連續達標天數、督導警報（落後、被退回、高信心答錯、低正確率）、12 週熱度圖、番茄鐘。
- **Agent 督導**：每天讀 `bridge/progress.json`，寫督導評語與當天任務到網站。
  - Claude 排程：每天早上（批改＋督導＋推播今天第一步）和晚上（批改＋沒做完就提醒）各一次，做法見 AGENTS.md 第 7 節（電腦需開機、Claude 桌面版開著）。
  - Windows 排程（可選）：執行 `setup_daily_task.bat`，每天 07:30 跑 `daily_supervise.bat`。有安裝 Claude Code 就用 AI 督導，否則用 `agent.py supervise --auto` 的規則式督導。

## 資料夾

```
start.bat                 啟動網站
server.py                 本機伺服器（只用 Python 標準函式庫）
agent.py                  Agent 用的指令工具（watch／reply／grade／supervise／quiz／report）
AGENTS.md / CLAUDE.md     Agent 工作規則
bridge/                   ← 網站與 Agent 交換的檔案（inbox、outbox、progress、state）
web/                      網站本體
content/lessons/*.md      教材原稿（改完執行 python build.py）
content/quiz/*.txt        題庫原稿
build.py                  把 content/ 編譯成 web/js/data.js
```

## 常見問題

- **進度存在哪？** 瀏覽器裡一份，`bridge/state.json` 自動備份一份；換瀏覽器時會自動從 `state.json` 還原。
- **數學式要網路嗎？** 不用，KaTeX 已經內建在 `web/vendor/`。
- **每章開頭的「跟著做一題」怎麼改？** 在 `content/examples/*.md`，格式寫在檔案開頭，改完執行 `python build.py`（或雙擊 `test.bat`，會順便檢查）。
- **想加章節或題目？** 照 `build.py` 開頭說明的格式寫在 `content/`，再執行 `python build.py`。
